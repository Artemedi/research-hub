# 0-CODE — автономные циклы разработки

- **Источник:** [0-SOFT/0-CODE @47f6a81724e87ff5e916f0eb146516d801a8fb28](https://github.com/0-SOFT/0-CODE/tree/47f6a81724e87ff5e916f0eb146516d801a8fb28), MIT, v2.1.1, 19.10.2026. Запись BK-029 / 28.09 старше проверенной версии.
- **Механика:** файловое состояние цикла, supervisor для Codex/OpenCode, hooks, журналы и ограничители. Итерации и стоимость ограничиваются только при настройке; код отклоняет неподдерживаемый cost cap для Codex. Это не гарантия сохранения чужой модели состояния или защит проекта.
- **Проверка:** 49 выбранных upstream unit tests прошли в изоляции; отдельный synthetic test строки команд показывает, что один конкретный `destructiveReason` не классифицирует `git reset --hard` и `kubectl delete ...`, но распознаёт `git push --force`. Команды не выполнялись; остальные слои разрешений и реальный цикл не проверены. Такое поведение описано автором как намеренный выбор границ этого фильтра.
- **Соответствия:** `agent-config`, `wiki-tasks`, `dsh-runtime` — сравнительное исследование guards, состояния и возобновления; `PROJECT_PROFILE_MATCH / NEEDS_EVIDENCE`, не готовая интеграция. `NO_PRODUCTION_APPROVAL`.
