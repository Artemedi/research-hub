# CodexSaver — агентная маршрутизация задач Codex по цене и риску

[Структурированная запись и связи](../catalog/studies/codexsaver.md)

**Тип:** open-source engineering source / MCP framework, не peer-reviewed study. **Первичный источник:** [fendouai/CodexSaver](https://github.com/fendouai/CodexSaver), pinned [`fe44dc105070c1f40eef29d9be76438edeab9987`](https://github.com/fendouai/CodexSaver/tree/fe44dc105070c1f40eef29d9be76438edeab9987), осмотр 23.11.2026; [`pyproject.toml`](https://github.com/fendouai/CodexSaver/blob/fe44dc105070c1f40eef29d9be76438edeab9987/pyproject.toml) — Python >=3.10, package 0.3.6, no declared dependencies. Последний доступный commit в main датирован 2026-05-31.

**Лицензирование:** pinned Git tree **не содержит LICENSE/COPYING**; `pyproject.toml` не декларирует лицензию. **LICENSE_NOT_ESTABLISHED** — исходники доступны для чтения, но это не открытая лицензия на воспроизведение, модификацию или интеграцию. До clarification upstream не копировать код в собственные проекты.

**Нормализованное описание вместо неудачного перевода:** `Codex orchestrates → cheaper model handles verified low-risk throughput → Codex retains risky judgment and final approval`. Конкретно: v1 keyword router для объяснений/поиска/доков/тестов; v2 bounded work packets, проверка патча и запуск заданных команд на копии дерева; v3 Python orchestrator с readonly specialists, локальными Agent Cards/Pi Agent, fallback `needs_codex`, временным деревом для агрегирования патчей. Применяется через MCP Codex; использование дешёвой модели требует внешнего провайдера или локального worker.

**Критическая оговорка:** наименования `readonly`, `sandbox`, `protected` не тождественны enforceable security boundary. В v1 [`codexsaver/verifier.py:62–80`](https://github.com/fendouai/CodexSaver/blob/fe44dc105070c1f40eef29d9be76438edeab9987/codexsaver/verifier.py#L62-L80) выполняет предложенные worker команды `shell=True` без независимого allowlist. V2 [`work_packet.py:290–424`](https://github.com/fendouai/CodexSaver/blob/fe44dc105070c1f40eef29d9be76438edeab9987/codexsaver/work_packet.py#L290-L424) применяет патч в `tempfile`/copytree, но проверки выполняются под правами процесса с `shell=True`, не в OS namespace/container. V3 `readonly` задаётся prompt-инструкцией [`orchestrator.py:875–892`](https://github.com/fendouai/CodexSaver/blob/fe44dc105070c1f40eef29d9be76438edeab9987/codexsaver/orchestrator.py#L875-L892); [`pi_agent.py:25–56`](https://github.com/fendouai/CodexSaver/blob/fe44dc105070c1f40eef29d9be76438edeab9987/codexsaver/pi_agent.py#L25-L56) запускает установленную CLI-команду как дочерний процесс без принудительной OS-isolation.

**Benchmark:** опубликованы пять v3.6 readonly-задач и **98% estimated token-cost savings** на модельной цене Codex, **не** замер полного end-to-end использования Codex включая оркестрацию/review/retry; в старом v3 project benchmark **2/5** задач успех. V3.6 patch-success benchmark — **детерминированное воспроизведение фиксированных выходов**, не live performance improvement. Источники: [readonly cost benchmark](https://github.com/fendouai/CodexSaver/blob/fe44dc105070c1f40eef29d9be76438edeab9987/docs/benchmarks/v36-pi-agent-benchmark-2026-05-19.md), [v3 benchmark](https://github.com/fendouai/CodexSaver/blob/fe44dc105070c1f40eef29d9be76438edeab9987/docs/benchmarks/v3-project-benchmark-2026-05-15.md), [patch benchmark](https://github.com/fendouai/CodexSaver/blob/fe44dc105070c1f40eef29d9be76438edeab9987/docs/benchmarks/v36-patch-success-benchmark-2026-05-31.md).

**Потенциальная применимость:** research-only архитектурный comparator для `agent-config`, `dsh-runtime` и `dsh-paper2agent`: cost-aware read-only triage и explicit final review gate, **без установки upstream MCP и без передачи исходников/ключей третьим лицам**. Ни одна integration seam не верифицирована. Тестировать только synthetic offline fixtures/независимым evaluator.
