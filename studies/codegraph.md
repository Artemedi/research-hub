# CodeGraph — инкрементальный локальный граф исходного кода для coding-агентов

[Структурированная запись и связи](../catalog/studies/codegraph.md)

**Тип:** open-source engineering project, а не рецензируемое исследование. **Pinned revision:** [`colbymchenry/codegraph@73c6cff66e525a92bff65675b6b0c46687e91ef1`](https://github.com/colbymchenry/codegraph/tree/73c6cff66e525a92bff65675b6b0c46687e91ef1), commit 2026-11-23; review 2026-11-24. `@colbymchenry/codegraph` **1.6.4**, [MIT](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/LICENSE). Source reviewed statically; repository contains working TypeScript implementation, Rust kernel, MCP, SQLite schema and ~981 test files, but **no cloned source dependencies or benchmark tools executed**.

**Source-confirmed architecture:** [`src/index.ts`](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/index.ts) exposes `indexAll/sync/searchNodes/getCallers/getCallees/getImpactRadius/buildContext/watch`. [Tree-sitter extraction](https://github.com/colbymchenry/codegraph/tree/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/extraction), [Rust kernel](https://github.com/colbymchenry/codegraph/tree/73c6cff66e525a92bff65675b6b0c46687e91ef1/codegraph-kernel), import/call reference resolution, SQLite (`node:sqlite`) with [FTS5 schema](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/db/schema.sql), traversal, context-builder, MCP query tools. A graph query can return linked function/route/handler code and impact radius without repeated source-search calls. This is *static approximation*, not proof of dynamic runtime call flow, T-SQL semantics, reflection or dependency injection resolution.

**Freshness is best-effort with explicit guardrails, not «never stale»:** [`src/sync/watcher.ts`](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/sync/watcher.ts) watches file events and debounces sync while a supported process is running. [`src/sync/watch-policy.ts`](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/sync/watch-policy.ts) disables watches under `CODEGRAPH_NO_WATCH=1` and automatically on WSL2 Windows drive mounts. [`src/mcp/answer-freshness.ts`](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/mcp/answer-freshness.ts) hashes contributing files with a **200-file / 8-MiB / 250-ms cap**, reporting excess as `unchecked`, and detects changed sources as `stale`. Worktrees/branch flips/index-on-disk may also require re-sync and independent assertion of repo revision. Source facts are not guaranteed to match runtime semantics.

**«100% local» requires a configured egress policy:** indexing/graph store are local and the implementation does not require external embeddings or an API key, but [`TELEMETRY.md`](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/TELEMETRY.md) and [`src/telemetry/index.ts`](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/telemetry/index.ts) disclose **default-on opt-out anonymous usage telemetry to `telemetry.getcodegraph.com`**, plus background release-version GET from GitHub. Upstream says telemetry sends no code/path/symbol/query values, but independent network capture and backend attestation were **not performed**. Use `DO_NOT_TRACK=1 CODEGRAPH_TELEMETRY=0 CODEGRAPH_NO_UPDATE_CHECK=1` and OS-level deny egress if a strict offline boundary is required. Model-driven agents may separately send graph's verbatim source snippets to their chosen external LLM providers; CodeGraph local storage cannot prevent that.

**Integration is real but changes agent configuration:** [`src/installer/targets/hermes.ts`](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/installer/targets/hermes.ts) registers MCP in `$HERMES_HOME/config.yaml` and deliberately avoids modifying `platform_toolsets` to prevent hiding existing MCPs (regression noted in comment). [`src/installer/targets/dsh.ts`](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/installer/targets/dsh.ts) writes `$DSH_HOME/cordis.patch.yml` and `AGENTS.md`; the supported adapter references upstream DeepSeek Harness and may not match an independently modified `dsh-runtime`. [`src/installer/targets/claude.ts`](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/installer/targets/claude.ts) modifies MCP and prompt hooks. Never run global `codegraph install` or `curl | sh` on real profiles without a sandbox and diff review. `includeIgnored` can opt-in gitignored trees; ensure no private secrets/backups/SQL dumps are indexed and passed into model context.

**Benchmarks must retain counterevidence:** [README](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/README.md) reports developer-owned **7 repos × four trials per arm**: 88% fewer tool calls, 53% faster, 62% fewer processed tokens and 44% cheaper on selected architecture questions, with contamination controls disclosed. Not independently reproduced or shown to improve solution correctness. Earlier [37-case language matrix](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/docs/benchmarks/codegraph-ab-matrix.md) finds **76% fewer file reads but $15.4 with vs $13.8 without** (single-flow workload); tiny repos can be slower. [Residual context occupancy](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/docs/benchmarks/residual-context-occupancy.md) reports **~80% more resident retrieval context** across the same seven repos; reducing processed tokens and increasing long-session context pressure are simultaneously possible. Benchmarks are *developer-reported*, not independently signed per-project outcomes.

**Portfolio applicability:** [`Artemedi/project-registry@91a0ca742a3225f6c4683b51031e8bbb595fdab8`](https://github.com/Artemedi/project-registry/tree/91a0ca742a3225f6c4683b51031e8bbb595fdab8), all 45 `PROJECT.md` purpose profiles screened. Five **documentary candidates:** `AKUZ` (private mixed C#/Python + SQL/PowerShell, **no source/index exposure**), `dsh-runtime` (TypeScript/Cordis graph), `Harness` (cross-module adapters/probes), `HermesAgent` (live config **not** a test repo), `dsh-paper2agent` (Python source navigation, not production experiments). 40 deferred. Indexing T-SQL/PowerShell is **not demonstrated as first-class semantic extraction**, while C#/TypeScript/Python are supported. No cost/correctness/integration benefit measured for user's projects.
