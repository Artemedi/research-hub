# Unreal Agent — исходное видео и инженерные материалы

[Структурированная запись и связи](../catalog/studies/unreal-agent.md)

- **Исходный пункт:** [видео YouTube](https://www.youtube.com/watch?v=eFBSlgXG3U0), дата Telegram-закладки 26.09.2026 восстановлена из исторической сверки. Полный пользовательский транскрипт получен 05.11.2026, но его тождество оригинальной записи независимо не удостоверено.
- **История ограничения:** на 04.11.2026 видео и субтитры не удалось получить без YouTube-авторизации; [исходный отчёт о недоступности](../reviews/unreal-agent/2026-11-04.md) сохранён без ретроспективной подмены фактов.
- **Новый первоисточник:** 06.11.2026 изучены [официальная полная статья Unreal Labs от 22.09.2026](https://unreallabs.ai/blog/unreal-agent/), исходники [Unreal Agent @ a5f3fd1](https://github.com/unreallabsai/unreal-agent/tree/a5f3fd13032737142916523ae4344c392292f9d5) и публичные отчёты Harbor. Верифицированы детали event-driven coordinator, но опубликованные суммы экономии не воспроизведены независимо; [полный разбор и границы доказательности](../reviews/unreal-agent/2026-11-06-source-audit.md).
- **Позднейшая статья:** [06.10.2026, long-horizon agents](https://unreallabs.ai/blog/long-horizon-agents-at-half-the-cost/) — дополнительный инженерный контекст, отдельный benchmark и отдельная compaction-гипотеза, не замена первичному сентябрьскому материалу.
- **Research → Projects:** документально обоснованные кандидаты — `dsh-runtime` (исследовать асинхронное исполнение только после P0 security gate), `agent-config` (сбор метрик polling/tokens); `HermesAgent` и `sequential-rca` — вторичный triage. `dsh` — reference/control plane; `AKUZ` и `TelegramBot` — нет прямого контракта. Ни один runtime seam или экономический выигрыш на текущем HEAD не воспроизведён.
