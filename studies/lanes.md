**Проверенная продуктовая модель (по документации, а не исполнению):** [README](https://github.com/lanes-sh/app/blob/7b9cb385d1100ded8a74986f81472f8856840578/README.md), [Sessions](https://lanes.sh/docs/desktop/sessions), [Worktrees](https://lanes.sh/docs/desktop/worktrees), [Loops](https://lanes.sh/docs/desktop/loops): local-first **macOS Ventura+**, Tauri 2/React 19/Rust/SQLite (claimed), Kanban issue board, sessions using PTYs, branch/worktree association, diff and SQLite read-only inspection, Claude Code/Codex first-class, arbitrary CLIs as plain shells. Local MCP research preview on `http://localhost:5353/sse` can create issues, start/stop/resume and inspect sessions; loops can start additional workers, poll status, run checker and gate PRs. Optional remote-workspace sync, OAuth Github/Linear, Gateway provider overrides and separate Lanes Link.

**Критическая поправка для Bazzite/Linux:** [официальный quickstart](https://lanes.sh/docs/desktop/quick-start) и [проверяемый skill установки](https://github.com/lanes-sh/app/blob/7b9cb385d1100ded8a74986f81472f8856840578/plugins/lanes-desktop/skills/install-lanes-desktop/SKILL.md) требуют Darwin/macOS >=13 и Homebrew cask; non-Darwin останавливается на preflight. Нет подтверждённого Linux Desktop binary/source path; **не пытаться собирать Tauri из этого репозитория**. `Lanes Link` — отдельный продукт и репозиторий с отдельными разрешениями, не замена desktop app и не основание лицензировать Desktop.

**Сценарные риски / предел доказательности:**
- **Git worktree ≠ OS sandbox.** Рабочая папка и branch отделяются, но общие Git objects/refs, user ID, `$HOME`, сеть, credentials, локальные сервисы и ресурсы остаются в общем trust domain, пока отдельно не установлена изоляция. Код закрытого Desktop и безопасность автодеструкции `dirty` worktree **не проверены**.
- **MCP и команды дают полномочия запускать процессы.** В публичном [`lanes-sessions` skill](https://github.com/lanes-sh/app/blob/7b9cb385d1100ded8a74986f81472f8856840578/plugins/lanes-desktop/skills/lanes-sessions/SKILL.md) `lanes_start_session` создаёт **новую** сессию каждый вызов; повтор вызова при delayed response может породить дубликаты. `lanes_resume_session` документирован лишь для Claude. Модель ACL/loop isolation/auth сервера в Desktop исходно не проверялась; localhost MCP без жёсткой авторизации требует threat review.
- **Небезопасные конфиги и автоматизация:** [`.lanes/quick-actions.json`](https://github.com/lanes-sh/app/blob/7b9cb385d1100ded8a74986f81472f8856840578/.lanes/quick-actions.json) *показывает* шаблоны shell `git merge`, AI «Complete & Merge», publish/release; [`lanes-bridges`](https://github.com/lanes-sh/app/blob/7b9cb385d1100ded8a74986f81472f8856840578/plugins/lanes-bridges/skills/github-lanes-bridge/SKILL.md) содержит пример fan-out с `dangerously-skip-permissions`; это не доказанная уязвимость Desktop, но демонстрирует необходимость явного user/security gate перед write/push/merge и запрещённых flags.
- **Граница секретов:** [Gateway docs](https://lanes.sh/docs/desktop/gateway) говорит о передаче key как **переменной окружения процесса** (не аргумент CLI/ps). Это всё равно доступно запущенной модели/процессу и может наследоваться дочерними процессами; не является OS-level secret isolation. [Settings](https://lanes.sh/docs/desktop/settings) предупреждают, что некоторые `.lanes/cli-flags.json` env entries попадают в scrollback/`ps` и репозиторий. Логи/PTY, MCP terminal-read, GitHub OAuth и crash reports требуют отдельного анализа.
- **Remote/privacy:** README заявляет local-first и opt-in remote, но также говорит «crash reporting on by default». Репозиторий не содержит Desktop source / protocols / policy code для независимой проверки каналов передачи. Подключённые LLM CLI продолжают работать со своими провайдерами; local-first board не значит offline execution.
- **Работа циклов — документально разумна, но не гарантия:** [официальный Loops guide](https://lanes.sh/docs/desktop/loops) требует hard max iterations, wall-clock timeout, independent checker, real tests и human review; это **workflow proposal**, не воспроизводимая security/performance аттестация runtime. Benchmarks на project throughput/cost/merge conflict/agent correctness в pinned публичном repo отсутствуют.
