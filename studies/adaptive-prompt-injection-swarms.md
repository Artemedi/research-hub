# Scaling Adaptive Prompt Injection Attacks with Agent Swarms

- Источник: [arXiv:2611.11861v1](https://arxiv.org/html/2611.11861v1), первичная публикация 2026-11-09. FULL_TEXT_VERIFIED: авторский HTML с методикой, результатами и анализом. Текст CC BY 4.0; публичный код авторского optimizer не подтверждён.
- Метод: 100 синтетических сценариев, 249 инструментов в 53 доменах, несвязанный с пользовательской задачей tool call как цель атаки; 8 команд × 2 атакующих агента, до 320 запросов к defender на сценарий.
- Результаты авторов: при сильнейшем атакующем Gemini 4 Argon ARR после полного бюджета 66% у Gemini 4 Argon и 1–10% у шести других моделей. ARR — доля сценариев, устоявших перед атакой, а не безопасность реального приложения.
- Ограничения: у Gemini отключены внешние safety/prompt-injection mitigations, synthetic tool outputs, дорогостоящий адаптивный поиск, независимое воспроизведение авторского optimizer недоступно; отсутствие сравнения на DSH.

Без сети, без реальных credentials, ≤4 CPU / 4 GiB / 120 mock rollouts. Gate: 0 unauthorized dispatch, без падения benign success, p95 ≤110% A.
