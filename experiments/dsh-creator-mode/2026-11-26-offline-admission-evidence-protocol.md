# DSH Creator Mode — проверка сохранённого офлайн-результата

1. Использовать чистый checkout `agent-skills@8170c5fd92de212132bca7374bb050ac635a2c01`. Запустить его штатные тесты каталога и формата навыков. Сопоставить назначение тестов с требованиями к проверке плагинов.
2. Сверить зафиксированный отчёт от 06.11 с байтами исходника плагина и манифеста. Сверить длину исходника, область опыта, все девять проверок и записанный режим изоляции.
3. На копиях в памяти проверить семь изменений: другие байты исходника или манифеста, пропущенную проверку очистки, неуспешную проверку редактирования, попытку переименовать область в полное тестирование Creator, другой хеш проверяющего и отсутствие записанного rootless-режима. Два повтора должны совпасть.
4. Отдельно сверить версии по манифестам источника DSH. Для настоящего прогона Creator нужны сведения о собранном и развёрнутом артефакте, доступном провайдере и разрешённой изолированной среде.

[Скрипт](offline-admission-evidence.py) принимает путь к `agent-skills`. Нужны Python, Git и PyYAML для штатных тестов проекта. Скрипт читает сохранённые материалы. Код плагина и DSH не запускаются.
