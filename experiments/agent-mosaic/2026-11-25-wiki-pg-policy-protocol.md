# Agent Mosaic — контроль выдачи сравнений Wiki_PG

1. Собрать временную публикацию штатным сборщиком Wiki_PG на `d55721bb99bff25fae352341cfd630c048693d6b`. Для четырёх вымышленных хостов записать по два снимка с тремя числовыми полями: память, число CPU и время работы. До запуска вычислить SHA-256 снимков и независимые ожидаемые разницы.
2. Через штатный read-only MCP stdio получить сравнения. Проверить обе стороны по идентификатору источника, хешу и времени снимка. В лабораторной политике каждый источник разрешён. Изменения памяти и числа CPU разрешены по отдельности, а их совместная выдача для одного хоста в пределах одной сессии запрещена. Время работы предоставляется без этого ограничения.
3. Сравнить три варианта: проверка источников по отдельности, проверка запрещённых сочетаний в одном ответе, проверка сочетаний по уже выпущенным фактам сессии. Лабораторный выход содержит только проверенные поля и числовые разницы. При отказе или неполных доказательствах выдаётся пустой список. Проверка неполного ответа удаляет одну запись источника из локальной копии ответа.
4. Для каждого хоста прогнать семь сценариев: одно поле памяти, одно поле CPU, оба поля вместе, два раздельных вызова в каждом из двух порядков, память с временем работы, неполная атрибуция. Это 28 сессий и 36 попыток выдачи на подход. Оракул независимо проверяет фактически опубликованные ключи и значения из исходных снимков. Успех: сессионный контроль останавливает все 12 закрытых сочетаний и сохраняет 20 разрешённых выпусков. Неполная атрибуция должна оставить 4 попытки без данных во всех подходах.

Область проверки — структура ответа и применение заранее заданной политики к искусственным фактам в пределах одного сеанса и пары снимков. Лабораторный контроллер расположен после MCP-ответа и моделирует правила выдачи пользователю. Состояние сеанса занимает по одному ключу на выпущенное поле. Проверка проходит по строкам сравнения и объединяет ключи текущего ответа с ключами сеанса. Не измеряются свободный текст, подлинные политики доступа, время работы на продуктивном объёме, идентификация пользователей и переход между сессиями. [Agent Mosaic, §7](https://arxiv.org/html/2610.30418v1#S7)
