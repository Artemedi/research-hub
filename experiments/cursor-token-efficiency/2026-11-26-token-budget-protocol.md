# Cursor Token Efficiency — локальный подсчёт входа

Нужны Python 3.11, Node.js 26 и `tiktoken==0.13.0`. До опыта подготовьте словари `cl100k_base` и `o200k_base` через `tiktoken.get_encoding`. Сетевое получение словарей во время прогона запрещено самим скриптом. Используйте чистый checkout DSH Runtime на `b6a1635b1200071754e2871b9d9453368e6daf23`.

```text
python -P -B experiments/cursor-token-efficiency/token-budget.py <pinned-dsh-checkout>
```

1. Сформировать каталоги из 4, 12 и 24 искусственных схем с описаниями на английском, русском и китайском. Измерить штатную оценку DSH и локальную токенизацию того же сериализованного массива.
2. Сравнить полный запрос, запрос с двумя основными инструментами и поиском, а для редкого инструмента — сумму двух запросов. Во второй запрос включить повтор исходного контекста и две короткие записи о поиске. Выбор нужного инструмента задаёт тест.
3. Сравнить число одинаковых начальных токенов при обратном порядке схем и при восстановлении первоначального порядка из того же множества. Сверить повторяемость полного JSON.

Измеряется токенизация лабораторного JSON и условных сообщений о поиске. Провайдер может иначе сериализовать схемы и управлять кэшем. Выходные токены, фактические счета, задержка поиска и точность выбора моделью остались вне измерения.
