# Karpathy AutoResearch — метрика и контрольный критерий в Paper2Project

1. Использовать чистый `dsh-paper2agent@c3bbe09bddf54b0efdcc0da1f17e1446dd35a4fd`. Зафиксировать основной прирост не менее двух единиц и контрольное качество не ниже 10. Для шести сценариев заранее задать ожидания, измерения и наличие закреплённого эталона. Повторить каждый сценарий на четырёх исходных значениях.
2. Зарегистрировать план штатным интерфейсом. Для контрольных случаев с эталоном приложить файл ожиданий с хешами дерева исходников и входов. Записать искусственные результаты в форме запечатанной записи Paper2Project. Оба варианта команды остаются неисполненными.
3. Сравнить принятие по одному порогу прироста с фактическими состояниями штатного отчёта. Сверить состояния до проверки, после обычной проверки и после попытки подтвердить метод, данные и эталон отдельным синтетическим проверяющим.
4. Требовать точного совпадения результатов двух прогонов. Основной порог должен принять 20/24 случаев. Штатные измерительные критерии должны принять 8/24, из которых только 4/24 проходят отдельное подтверждение эталона.

[Скрипт](paper2project-holdout.py) принимает путь к закреплённому checkout. Используются Git, Python и временное хранилище. Таблица исходов играет роль синтетического эталона. Модели, реальные обучающие выборки и контейнеры в тесте не используются.
