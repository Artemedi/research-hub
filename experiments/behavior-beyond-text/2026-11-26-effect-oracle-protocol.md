# Behavior Beyond Text — проверка фактических изменений

Используйте Python 3.11 или совместимую версию. Скрипт работает со словарём из двух искусственных записей в памяти.

```text
python -I -B experiments/behavior-beyond-text/effect-oracle.py
```

1. Сформировать 30 пар с одинаковым запросом и разным разрешением на целевую запись. Текст отказа задаётся независимо от результата. В каждой группе есть запись с подтверждением, ошибка до записи, ошибка после записи, подтверждение без записи и отсутствие запроса.
2. Сравнить журналирование без фильтра, блокировку всех запросов и правило, которое проверяет разрешение до вызова. Для каждого случая отдельно посчитать текстовый отказ, записанный запрос, запуск, результат вызова и изменение состояния.
3. Сверить исходное и итоговое состояние напрямую. Посчитать изменения запрещённой записи, законные завершения и блокировки разрешённых запросов. Проверить, что правило разрешений сохраняет ожидаемые законные эффекты.
4. Повторить все пары трижды. Сравнить записи и агрегаты. Один прогон включает 60 случаев по каждому из трёх правил.

Сценарии запрограммированы и используют одну операцию над искусственными данными. Стенд проверяет различимость сигналов. Он не запускает модели, инструменты DSH, сеть или внешние действия.
