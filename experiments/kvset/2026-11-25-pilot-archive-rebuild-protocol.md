# KVSET — восстановление содержимого пилотного пакета

1. Получить Git-объекты пилота `dsh-paper2agent@6418c2397fd16a73cba58990fca2f6801e01148c`, текущего проекта `c3bbe09bddf54b0efdcc0da1f17e1446dd35a4fd` и авторского кода `fab8ac99017e4ca6f22c811ee874b72a2e1a7296`. Для авторского кода достаточно временного репозитория с объектами этого коммита. [Репозиторий авторов](https://github.com/llc-kc/kv_cache_capacity_estimator)
2. Сверить два исторических отчёта о пакете. Восстановить файлы по их путям, а два служебных JSON — по историческому рецепту сборки. Проверить точный набор записей и SHA‑256 каждого файла. Отдельно сравнить файлы запуска с текущим проектом.
3. Дважды собрать ZIP в памяти. Открыть архив, проверить CRC, порядок уникальных записей и SHA‑256 каждого извлечённого файла. Сравнить размер и хеш всего ZIP с историческим манифестом.
4. Повторить со стандартным zlib и, при наличии, с `--zlib-ng`. Побайтовое восстановление считается подтверждённым только при совпадении полного хеша и размера. `--output` создаёт файл только в этом случае и требует свободный путь.

[Скрипт](rebuild-pilot-archive.py) принимает пути к двум локальным Git-репозиториям. Базовый режим использует стандартную библиотеку Python. Для дополнительного сравнения использован `zlib-ng==1.1.0`. Для прогона не нужны модели, GPU или исполнение кода из ZIP.
