# Static API warnings: Paper2Project transfer protocol

Frozen before the first measured run on 2026-11-25.

- Source: arXiv:2604.07755v3, PDF SHA-256 `e87497abdfc08f6aca58580a642d5c3188bc4a3bd2d5884f68c55032214996c6`. Transfer the paper's distinction between a diagnostic and a correct reason.
- Target: `Artemedi/paper2project@57991e6681ad683a5be8111b7d470fed5d53625b`. Compare eight actual App methods. Node v24.11.1, Pyright 1.1.407, basic mode, package SRI `sha512-zU+peTFEVUdokNQyUBhGQYt+NWI/3aiNlvBbDBSsn5Ti334XElFUs+GDjQzCbchYfkT+DvMAT3OkMcV4CuEfDg==`.
- Forty authored calls, five variants per method: valid direct, valid dynamic, invented method, invented keyword, invalid dynamic. Each case is run against the actual project with fabricated Markdown inputs and a temporary workspace. An error must match the invented identifier or keyword in both the diagnostic and runtime exception to count for the right reason.
- A: Python syntax compilation followed by actual runtime. B: same checks with Pyright before runtime. Compare incremental warnings before execution, conditional on compile succeeding. Runtime outcomes are the correctness oracle and are checked against expectations written before the run. A valid dynamic call is a negative control. An invalid dynamic call probes missed cases.
- Primary screening criterion: at least 12/16 of the direct API mistakes receive a target diagnostic, and no actionable warnings on valid calls. Assess dynamic failures separately as out-of-scope for this gate. Three repeats of the same batch, measure diagnostic false positives, misses and relative batch wall time. Same generated calls with fresh Python App workspaces. Use no API, model or Podman.
- This checks only API diagnostics in authored adapters. Scientific correctness, behavior of generated programs and security do not follow from these results.

## Reproduction

Use the clean target checkout, the pinned Node binary, and the verified Pyright package archive extracted into a disposable directory. Run from the target checkout with `PYTHONPATH=src PATH_TO_PYTHON ABSOLUTE_EXPERIMENT_PATH . NODE_BINARY PYRIGHT_PACKAGE_INDEX_JS`. The script writes the receipt to stdout and uses only temporary inputs and a temporary App store.
