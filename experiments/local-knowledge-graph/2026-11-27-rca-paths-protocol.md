# Local Knowledge Graph × sequential-rca — обход графа доказательств

1. Подготовить файл `src/mpe_lkg/graph.py` из Local Knowledge Graph на ревизии `58fce402c7d15a3f5abcc8d0b1e920c1be5071b5` и чистый checkout sequential-rca `13fa0c910c75d9e3b79c758bcba473a6406e008c`. Использовать Python 3.11, NetworkX 3.6.1 и NumPy 1.26.4.

   ```text
   python experiments/local-knowledge-graph/rca-paths.py <pinned-graph.py> <pinned-rca-checkout>
   ```

2. Построить штатным проектором RCA 60 графов с вымышленными доказательствами. В пяти группах по 12 проверить прямую поддержку, обратный путь, противоречие, обход через общую гипотезу и такой обход при наличии прямой альтернативы.
3. Подставить одинаковые веса рёбер в три ветки. В первой использовать исходный поиск Local Knowledge Graph. Во второй добавить направление. В третьей сохранять направление и разрешать только типы связей, заданные для поиска заявленных подтверждений. Сверить путь или отсутствие пути с заранее указанным эталоном. Доказательства и черновики проходят штатную проверку RCA перед построением графа.
4. Повторить прогон с другими идентификаторами. Сравнить счётчики совпадений, обратных рёбер и проходов по противоречиям.

Веса созданы стендом и задают приоритеты двух конкурирующих путей. Они не получены от модели. Прогон работает в памяти, не оценивает масштабирование, качество реальных диагнозов и время анализа. [Скрипт](rca-paths.py) · [Данные](../../data/results/local-knowledge-graph/2026-11-27-rca-paths.json)
