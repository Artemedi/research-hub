# Covert Assistance — проверка полномочий получателя

Используйте Python 3.11. Стенд обрабатывает искусственные записи журнала с четырьмя метками происхождения: сообщение, артефакт, результат инструмента и делегирование. Для всех записей используется одна проверка перед локальным эффектом.

```text
python -I -B experiments/covert-assistance/recipient-authority.py
```

1. Задать полномочия в отдельном тестовом реестре. Для каждого типа записи проверить согласованную передачу, получателя без права записи, отзыв полномочий, пропущенного получателя, другую область записи, отправителя без права записи и отсутствие связи с исходным запросом.
2. Сравнить проверку отправителя и проверку обоих участников. Для второго режима отсутствие получателя или связи с исходным запросом останавливает изменение.
3. Сверить ожидаемые исходы с изменениями в отдельном словаре. Учесть неожиданные и пропущенные эффекты. Повторить 28 случаев трижды.

Метки канала задаёт стенд. Он не проверяет происхождение метаданных или содержимое передаваемых данных. Все записи вымышлены. [Скрипт](recipient-authority.py) · [Результат](../../data/results/covert-assistance/2026-11-26-recipient-authority.json)
