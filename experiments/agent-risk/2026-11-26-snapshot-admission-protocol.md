# Agent Risk — допуск снимка для офлайн-повтора

Используйте Python 3.11 или совместимую версию и чистую копию публичного companion-репозитория на `a1ab24aaf3c1e5bfbe47a24eaf4cf411bf0b3f1b`. Скрипт импортирует только функции конечного расчёта из `checks/verify_replay.py` и работает на стандартной библиотеке.

```text
python -I -B experiments/agent-risk/snapshot-admission.py <pinned-agent-risk-checkout>
```

1. Перебрать четыре типа записей, два исхода до границы и четыре значения оставшегося бюджета. Исходный код автора определяет первое расхождение и меру наблюдаемых исходов. Стоимость остановки здесь выражена как сохранение ошибочного исхода, который уже произошёл до остановки.
2. Для продолжений проверить наличие и допустимость состояния, одинаковый номер границы, контекст и хеш снимка. Смена объявленной версии среды или объявление политики до границы блокируют допуск. После допуска продолжить только искусственную задачу по счётчикам. Сравнить результат с независимо заданной таблицей.
3. Для каждого продолжения восемь раз изменить отдельное условие. Исход должен остаться неопределённым при отсутствии бюджета или контекста, отрицательном бюджете, неверной границе, другом контексте, изменённом бюджете, другой версии среды или заранее объявленной политике.
4. Сравнить два исходных журнала с одинаковыми наблюдениями, но разным оставшимся бюджетом. В синтетической проверке один бюджет приводит к ошибке, другой позволяет избежать её. Повторить весь перебор трижды и сравнить JSON.

Хеш проверяет согласованность с известной записью на границе. Испытание предполагает доверие к этой записи и к заявленной версии среды. Оно не проверяет реальный журнал, обнаружение скрытой смены среды или поведение агента.
