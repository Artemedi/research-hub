# Decision Geometry Harness — раздельная проверка порядка

Используйте Node.js 26 и чистую копию DSH Runtime на `b6a1635b1200071754e2871b9d9453368e6daf23`. Скрипт проверяет SHA-256 модуля заголовка и сериализатора. Локальная привязка импортов использует штатные функции состава сообщений и сравнения конфигурации. Ветка обработки ошибок провайдера исключена из стенда.

```text
node experiments/decision-geometry-harness/order-isolation.mjs <pinned-dsh-checkout>
```

1. Сформировать 60 синтетических историй по два вызова и два результата. Для каждой сравнить исходный JSON, обратный порядок списка инструментов и обратный порядок свойств схемы при неизменном списке.
2. Проверить совпадение структуры допустимых полей после нормализации отдельно от байтов. Изменение обязательного поля служит контролем реального изменения контракта.
3. Проверить, считает ли штатное сравнение заголовки одинаковыми. Свернуть запись исходного и изменённого заголовков штатной функцией.
4. Проверить идентификаторы вызовов и результатов по исходным записям. В отдельной копии каждого случая подставить неверный идентификатор результата и проверить, что независимая сверка его обнаружит. Повторить все случаи трижды и сравнить хеши.

Прогон ограничен локальным построением JSON. Провайдер, модель, кэш и выполнение инструментов не используются. [Скрипт](order-isolation.mjs) · [Результат](../../data/results/decision-geometry-harness/2026-11-26-order-isolation.json)
