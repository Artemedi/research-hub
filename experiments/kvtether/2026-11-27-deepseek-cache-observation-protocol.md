# KVTether × DSH Runtime — наблюдаемость KV-кэша

1. Подготовить чистый checkout DSH Runtime на `b6a1635b1200071754e2871b9d9453368e6daf23`, Node.js 26 и отдельную установку `eventsource-parser@3.1.0` по версии из lock-файла DSH. Передать путь к каталогу пакета в `node_modules`.

   ```text
   node experiments/kvtether/deepseek-cache-observation.mjs <pinned-dsh-checkout> <eventsource-parser-directory>
   ```

2. Для каждой из трёх форм счётчика попаданий построить 16 пар запросов и ответов. Сравнить нативную форму, совместимую форму и их совместную передачу. В каждой паре оставить счётчики и текст одинаковыми. Изменить только лабораторные поля с размещением и удержанием блоков.
3. Сравнить байты запросов после штатной сериализации. Передать подставные SSE-кадры в штатные парсер и преобразователь. Сверить события и ожидаемые счётчики. В контрольных вариантах изменить текст запроса или число попаданий. Оба изменения должны быть видны.
4. Повторить матрицу трижды. Сравнить число совпавших пар и прошедших контролей.

Поля размещения введены стендом. Они не представляют контракт API DeepSeek. Транспортный модуль сверяется по хешу и читается как исходник. Сам HTTP-запрос не исполняется. Стенд не измеряет задержку, размещение блоков или ресурсы реального сервера.
