# Silent Cue Loss: Paper2Project PDF transfer protocol

Frozen before the first measured run on 2026-11-25.

- Source: arXiv:2610.30026v1, PDF SHA-256 `a1634fad8737ed6ff5524ff7f943ba48ee962cf0633e40b6cf356fb5608cf06c`. Use the PDF extension in Appendix S8 as the motivation for a cue-retention check.
- Target: `Artemedi/paper2project@57991e6681ad683a5be8111b7d470fed5d53625b`. Use pypdf 6.18.1, already installed for Paper2Project.
- Hypothesis: a derived representation of a controlled digital PDF can preserve a foreground color observation through the existing research import and job-read path without losing its text.
- Fixture labels: each of 30 PDFs has four lines. Their authored order and labels are plain/reset black, scoped red, restored black with literal color-marker text, and decorative blue. Even documents put red before the first black line and odd documents put it after that line. A deliberately unmarked black line contains a literal red marker. Colors are formatting observations and carry no rule semantics.
- A: unmodified Paper2Project PDF import, followed by job creation and read. B: parse the fixture's small subset of PDF operators, write JSON records with separate color and text fields to a text file, then use the same application import, job creation and read. The B parser is local experimental code for generated fixtures.
- Oracle: authored text, order and red labels come from the fixture manifest created before either import. The parser output and baseline have no role in assigning these labels. A mutation treating all colored text as red must produce 30 false positives.
- Acceptance: exact text and order for 120/120 lines in each repetition, A expected red recovery 0/30, B red precision and recall both 1.0 with no positive on black or blue controls, and byte count for B's citable text at most 4× A. Report median and p95 end-to-end timings without a latency pass criterion. Three repetitions, alternate arm order by document and repetition, use fresh local workspaces. No model or real policy documents.
- No scope for arbitrary PDFs, OCR, geometry/highlights, DOCX, compliance decisions, resource-hardening or author benchmark reproduction. Use only generated PDFs in the experimental parser.

## Reproduction

In Linux or WSL, use the clean target checkout and the tested pypdf dependency in its Python environment. Run from the checkout with `PYTHONPATH=src PATH_TO_PYTHON ABSOLUTE_EXPERIMENT_PATH .`. The script writes the counters and timing to stdout and uses temporary input and state directories.
