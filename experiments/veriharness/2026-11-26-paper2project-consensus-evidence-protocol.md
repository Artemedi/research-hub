# VeriHarness — сравнение голосования с проверкой доказательств

1. Использовать чистый `dsh-paper2agent@c3bbe09bddf54b0efdcc0da1f17e1446dd35a4fd`. Для восьми исходных значений создать книгу операций, контрольную квитанцию и сводку. Пять предложенных ответов на случай используют один и тот же набор доступных материалов.
2. Проверить шесть вариантов. Это верное единогласие, ошибочное единогласие, верное меньшинство, большинство с неверной строкой цитаты, расхождение источников и спор без верного ответа.
3. Сравнить голосование по всем предложениям, голосование после штатного допуска цитат Paper2Project и проверку данных. В последнем режиме прочитать два зафиксированных документа через `App.read`, пересчитать сумму по книге и сверить её с квитанцией. Выбрать только допущенный ответ с этой суммой. При расхождении источников или отсутствии подходящего ответа воздержаться.
4. Повторить 48 случаев в новом временном хранилище трижды. Проверить отдельно верные и ошибочные ответы, отказы и число допущенных цитат.

[Скрипт](paper2project-consensus-evidence.py) принимает путь к закреплённому checkout. Нужны Python и Git. Ответы и материалы заданы стендом. Модели, агенты и внешние данные не используются.
