# Anthropic Agent Automations — отметки источников

Используйте Python 3.11 или совместимую версию. Стенд работает на стандартной библиотеке. Исходный пример прочитан по закреплённой версии и служит описанием метода. [Инструкция daily-brief](https://github.com/anthropics/claude-quickstarts/blob/8ef47d719eba5379ff8f38133f5defcc499e856f/managed-agents/daily-brief/agents/daily-brief/agent.md#L47-L63)

```text
python -I -B experiments/anthropic-agent-automations/source-bookmarks.py
```

1. Сформировать два источника с восемью изменениями и десятью моментами чтения. Задать отказ одного источника, появление записи с задержкой внутри окна, на границе и за его пределами, а также переход записи в другое состояние и обратно.
2. На тех же входах сравнить общую отметку без перекрытия, отдельные отметки без перекрытия и отдельные отметки с повторным чтением десяти минут. Запоминать последнее опубликованное состояние по источнику и идентификатору.
3. При ответе `ok=true` без идентификатора, отказе публикации и сухом прогоне проверить побайтное равенство состояния до и после. При подтверждении продвинуть только успешно прочитанные источники в вариантах с отдельными отметками. В стенде отметка — время завершённого чтения.
4. Сравнить записи искусственной службы публикации с независимо заданными ожидаемыми наборами. Посчитать пропуски, повторы и число прочитанных записей. Повторить каждый вариант трижды.

Служба публикации локальная. В контрольном ответе без идентификатора внешнего эффекта нет по конструкции. Поведение при поздно подтверждённом внешнем эффекте, конкурирующей записи и сбое между публикацией и локальным сохранением вне прогона.
