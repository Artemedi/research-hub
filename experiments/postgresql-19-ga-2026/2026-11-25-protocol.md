From the hub, set `PYTHONPATH` to the checkout's `Wiki_PG/ingestion` folder and run `python -B experiments/postgresql-19-ga-2026/2026-11-25-wiki-pg-settings-ab.py PATH_TO_WIKI_PG_CHECKOUT`. Only the standard library and the checkout's parser and SQLite modules are used. The script writes the receipt to stdout.
