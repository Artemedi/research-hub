# Drift Inspector — подготовка слепого скрининга B1

25 ноября 2026 года проверен повтор [замороженной выборки](2026-11-25-b1-protocol.md). Из локального снимка подготовлен пакет из всех 471 test-статей и 36 зафиксированных критериев. Пакет хранится локально. Разметка ещё не получена, поэтому число релевантных статей неизвестно. В этом прогоне не выполнялись поиск, извлечение ACC или кластеризация.

1. Скрипт проверяет корпус и хеш протокола. Он выгружает `blind-batch.json` с названием, аннотацией и случайно назначенным номером. Пакет не содержит тем OpenAlex, названий групп, рангов или выводов систем. Таблица соответствия `private-key.json` остаётся у оператора.
2. Владелец и независимый модельный судья используют один пакет и отдельные копии `labels-template.tsv`. Судья должен быть из другого семейства, чем экстрактор. Каждый размечает без доступа к ответам другого и к результатам моделей поиска. В каждой строке через запятую указываются ID релевантных и неясных запросов. Дефис означает пустой список, две пустые ячейки — статья ещё не рассмотрена. Остальные запросы рассмотренной статьи считаются нерелевантными по правилам скрининга.
3. Скрипт сверяет идентификатор пакета, исходные тексты и уникальность строк. Статья засчитывается один раз, если оба разметчика отметили релевантность хотя бы по одному и тому же запросу. Расхождения и неясные случаи не добавляются к подтверждённому числу. С 50 таких статей нижняя граница достаточна, даже если часть пакета ещё не просмотрена. Результат ниже 50 на неполной разметке оставляет допуск открытым.
4. Оператор подтверждает независимость и выбор судьи отдельно. Затем применяются остальные условия [протокола](README.md), включая раннюю проверку стабильности fit и фиксацию τ до тестового прогона. Разметка для допуска не используется для настройки или как замена B2.

```text
python -B experiments/drift-inspector/b1-relevance-gate.py prepare SNAPSHOT_DIR BATCH_DIR
python -B experiments/drift-inspector/b1-relevance-gate.py count BATCH_DIR OWNER.tsv JUDGE.tsv
```

`BATCH_DIR` создаётся вне Git-репозитория и должен отсутствовать до `prepare`. В `count` код 0 означает достижение численного порога, 1 — порог пока не достигнут, 2 — входные данные отклонены. Код 0 проверяет совпадение разметок, а независимость оценивает оператор. Публикуются только агрегаты и хеш пакета. [Машинная сводка подготовки](../../data/results/drift-inspector/2026-11-25-b1-relevance-preparation.json).

На синтетическом наборе из 52 статей проверены граничные случаи 49 и 50, совпадение по нескольким запросам для одной статьи, расхождение и пустая строка. Дубликат, конфликт меток, чужой хеш пакета, один файл для двух разметчиков и изменение байтов отклонены. На фактическом пакете с двумя пустыми шаблонами порог остался открытым.
