# Auto-Ontology — словарь терминов перед точным чтением Wiki_PG

1. Использовать чистый Wiki_PG `d55721bb99bff25fae352341cfd630c048693d6b`. Для шести наборов создать снимки двух инстансов с разными значениями одной настройки. Добавить кириллический псевдоним каждого хоста.
2. Сравнить точное имя поля и небольшой словарь. При единственном соответствии словарь передаёт каноническое поле штатному `SystemQueries.state`. В обоих режимах хост, порт и дата передаются штатному запросу.
3. Проверить восемь случаев, включая точный ключ, зарегистрированный псевдоним, пользовательский термин для двух хостов, неоднозначный и неизвестный термин, отсутствующее значение и неверный порт. Если поля нет в выбранном снимке, значение должно оставаться недоступным, даже если оно есть у другого хоста или в более раннем снимке.
4. Сверить число, канонический хост, порт, дату, путь и SHA‑256 с зафиксированными искусственными данными. Повторить 48 случаев в новом временном каталоге.

[Скрипт](wiki-pg-semantic-selectors.py) принимает путь к закреплённому checkout. Нужны Python, PyYAML и SQLite FTS5. Это стенд ручного словаря. NVIDIA Auto-Ontology, генерация SQL и сетевые сервисы не запускаются.
