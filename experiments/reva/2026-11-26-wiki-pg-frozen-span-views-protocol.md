# REVA — повторное использование оценок фрагментов Wiki_PG

1. Использовать чистый Wiki_PG `d55721bb99bff25fae352341cfd630c048693d6b`. Создать десять искусственных наборов. В каждом есть документ с обзором, редким исключением и часто используемым правилом, а также второй документ с тем же текстом, для которого оценки не заведены.
2. Три предварительных запроса к каждому известному документу дают счётчик подтверждённых фрагментов. Связать счётчик с путём, SHA‑256 и диапазоном строк. Зафиксировать оценки до проверки.
3. Сравнить первый подходящий по порядку фрагмент, первый фрагмент штатного лексического поиска и первый фрагмент по сохранённой оценке. Лимит — один фрагмент из одного и того же набора кандидатов. Если среди его кандидатов нет сохранённых оценок, использовать лексический порядок.
4. Проверить пять сценариев: частый вопрос, вопрос о редком исключении с общей лексикой, точный запрос об исключении, второй документ и обновлённая версия первого документа. Сверить текст каждого выбранного фрагмента с байтами источника и убедиться, что контрольные запросы не меняют оценки. Провести два прогона по 50 случаев.

[Скрипт](wiki-pg-frozen-span-views.py) принимает путь к закреплённому checkout. Нужны Python, PyYAML и SQLite FTS5. Частота выбора служит искусственным сигналом и не требует весов внимания или запуска модели.
