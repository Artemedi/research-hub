# Concordat — привязка подтверждения к предложению

Используйте Python 3.12 и чистую копию Concordat на `26fd8b1c3a823a4c6be39eedbe370a241623a4cc`. Установите пакет из этой копии в отдельное виртуальное окружение без необязательных SDK. На этапе сборки может потребоваться Hatchling. Перед прогоном скрипт сверяет установленные Python-файлы с исходниками побайтно.

```text
python -m pip install --no-deps <pinned-concordat-checkout>
python -I -B experiments/concordat/approval-binding.py <pinned-concordat-checkout>
```

1. Провести через штатные декораторы Concordat последовательность «просмотр, предложение, подтверждение, изменение, проверка». Стенд меняет только значения в словаре. Сделать пять вариантов тестовых записей для каждого из десяти случаев.
2. Сравнить три режима. Контроль без проверки применяет подставное изменение напрямую. Второй режим применяет штатный порядок и булев ответ согласующего. Третий дополнительно сверяет запись, версию, новое значение и срок подтверждения. Перед изменением он снова сверяет фактический запрос с показанным предложением.
3. Проверить точный набор эффектов независимым эталоном. Два положительных случая допускают ровно одно изменение каждый. Для повторного запроса проверяется отказ внутри той же сессии. Остальные случаи охватывают отсутствие согласия, отрицательный ответ, другую версию, запись или значение, истечение срока, ответ без привязки и изменение после согласования.
4. Повторить весь набор трижды и сравнить машинные отчёты.

Подтверждения и часы задаёт стенд. Запуск не использует моделей, внешних инструментов, подписанных удостоверений или рабочего хранилища. Сохранение подтверждения между перезапусками и параллельными действиями отдельно не проверялось.
