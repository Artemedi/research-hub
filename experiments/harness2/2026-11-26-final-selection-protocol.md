# Harness² — проверка выбора из готовых результатов

Используйте Python 3.12 или 3.13 и чистую копию Harness² на `6868817518876de8fd170c6a8354daca273b6191`.

```text
python -I -B experiments/harness2/final-selection.py <pinned-harness2-checkout>
```

1. Создать синтетические результаты задачи «сложить 2 и 3». Неизменный исходный вариант даёт 5. В группе из двух финальных вариантов есть ответ 4 и ответ 5.
2. Передать их исходной функции построения пула. Затем вызвать штатную функцию выбора с подставным ответом. Проверить правильный и неправильный результат по перечисленному идентификатору, отсутствующий блок выбора, неизвестный идентификатор и ошибку провайдера с условной стоимостью двух его попыток.
3. Проверить исключение недоставленного варианта, пустой пул и режим с единственным финальным вариантом. Сверить число обращений к подставному селектору, итоговый результат, отметку ошибки, условную стоимость и содержимое записи `selection.json`.
4. Сравнить выбранный ответ с независимым арифметическим эталоном. Повторить все восемь случаев трижды. Затем повторить весь запуск и сравнить отчёты.

Все входы находятся во временных каталогах. Результаты не содержат локальных путей. Долларовые значения заданы тестом для проверки учёта. Генерация вариантов, реальные запросы к модели и стоимость полного процесса отсутствуют. [Скрипт](final-selection.py) · [Результат](../../data/results/harness2/2026-11-26-final-selection.json)
