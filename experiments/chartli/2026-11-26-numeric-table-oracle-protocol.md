# Chartli — проверка графика по исходной таблице

Используйте Python 3.11, Node.js 26 и чистую копию Chartli на `3b39b97aeb564646437b2b7501b60541994d7575`. Исходные файлы нормализации и SVG сверяются по SHA-256. Зависимости Chartli устанавливать не требуется.

```text
python -I -B experiments/chartli/numeric-table-oracle.py <pinned-chartli-checkout>
```

1. Подать шесть искусственных таблиц напрямую в штатные `normalizeData` и `renderSvg`. В таблицах заданы длительности в секундах, метки времени, пропуск и один точно переводимый случай в микросекундах. Сырые значения остаются в секундах.
2. Разобрать SVG через Python ElementTree. Взять размеры области по осям и независимо вычислить ожидаемые координаты числовых шкал. Допуск координат — половина пикселя. Для сравнения нескольких рядов одинаковые длительности должны давать одинаковую высоту на общей шкале.
3. Сверить подписи времени, единицы, деления и числовые подписи точек. Для отсутствующего числа проверить, добавил ли график точку и какой подписью её снабдил.
4. Допустить график рядом с исходной таблицей только там, где координаты и подписи соответствуют ожидаемой шкале. Если график не прошёл, сохранить данные только как таблицу. Повторить все шесть случаев трижды и сравнить результаты и хеши SVG.

Стенд проверяет числовой контракт линейного SVG. Он не использует CLI-парсер, браузер, рабочие данные или исходники целевых проектов при выполнении.
