# Database Agent Observability — счётчик и запись события в Wiki_PG

1. Использовать чистый Wiki_PG `d55721bb99bff25fae352341cfd630c048693d6b`. Подготовить четыре начальных значения счётчика, включая ноль, и для каждого повторить 12 вариантов пары наблюдений и записанного события.
2. Сравнить рост двух чисел со штатным `interval_checks.measure`. Там, где нативный расчёт принимает пару, сверить дельту и скорость с независимой арифметикой. Проверить отказ при сбросе, другой области и отсутствии времени сброса.
3. Добавить отдельную проверку записи события. Она требует измеримого роста счётчика, совпадения хоста, порта и базы и времени события в интервале `(начало, конец]`. Проверить подходящую запись в середине и на правой границе, отсутствующую запись, обе границы времени, другой хост, порт и базу, а также запись при нулевом росте.
4. Трижды повторить 48 случаев. Сверить решение с зафиксированным эталоном и регистрировать ID только совпавших записей. Не выводить причину события из числа или совпадения по времени.

[Скрипт](wiki-pg-counter-evidence.py) принимает путь к закреплённому checkout. Нужны Python и Git. Пары наблюдений и записи искусственные. Подключение к PostgreSQL, сбор живой телеметрии и агенты не используются.
