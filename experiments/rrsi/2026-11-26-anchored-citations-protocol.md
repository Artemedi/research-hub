# RRSI — отбор правила привязки цитаты

Используйте Python 3.11 и чистые копии RRSI на `be50316e1db05914068a973f322770ef08ed7ba1` и agent-config на `489e074ab0daaadb732673c193047172a3744862`. Скрипт импортирует исходные функции проверки замечаний и отбора. Варианты правил вычисляются локально. Исполняются только функции из созданных для этого теста строк Python. Модель, сетевые вызовы и подбор изменений агентом в прогон не входят.

```text
python -I -B experiments/rrsi/anchored-citations.py --rrsi <checkout> --agent-config <checkout>
```

1. Сравнить текущий поиск цитаты во всём файле, проверку её начала на указанной строке и проверку начала в пределах одной соседней строки. Для многострочной цитаты правило применяется только к её началу.
2. Разбить шесть семейств функций на пары. В каждом из трёх прогонов пары для отбора, валидации и итоговой оценки различны. Функция отбора получает оценку привязки на первом наборе. Дополнительное правило допуска требует меньше ложных привязок и сохранения всех верных привязок на втором наборе.
3. Открыть итоговые примеры после выбора. Отдельно посчитать ошибки привязки и принятые цитаты, которые сопровождают ложное утверждение о поведении. Для второго счётчика сравнить заявленный результат с ответом тестовой функции на заранее заданном входе.
4. Повторить прогон и сравнить JSON. Он содержит разметку итоговых примеров, прогнозы, хеши тестовых исходников и сводки по трём наборам каждого прогона.

Шаблоны замечаний общие для всех семейств. Меняются выражения и их результаты, поэтому этот тест оценивает заданные случаи переноса между функциями. Он не проверяет перенос на новые типы ошибок или языки. [Скрипт](anchored-citations.py) · [Результат](../../data/results/rrsi/2026-11-26-anchored-citations.json)
