## 1. Concordat — Typed Sessions for LLM Agents

**Full primary source:** https://arxiv.org/abs/2610.37461 ; [PDF v2](https://arxiv.org/pdf/2610.37461v2) ; pages: 11 ; SHA-256: 40cdfc4cc918414bbb50485494003f45721a34dc0f1b2b773a5cdcbb5de18a31.
**Method/sample.** Python typestate/session-type API с конечным автоматом: агенту видны только действия в текущем state; illegal tool calls блокируются до side effects. Включает handoff budgets и проверку subclass protocol refinement. Проверено на τ-bench airline 50 задач и дополнительных run sets под simulated customer pressure.

**Authors outcomes (not independent reproduction).** У baseline GPT-4.1 изменения без требуемого yes в 13 из 50 задач, у Haiku 5.5 — в 29 из 128 task-runs; Concordat не пропустил таких нарушений при заданном критерии. Разница task success статистически значима не была.

**Limits and confounders.** Сам gate и метрика approval используют одинаковую keyword-based проверку yes: нулевое нарушение по определению gate не доказывает корректного человеческого согласия. Нужен structured approval; generic finite state для open-ended задач сложен; provenance/state persistence требует отдельной оценки.

**Smallest falsifiable experiment.** 50 synthetic inspect→propose→explicit structured approve→mutate→verify tasks. Prompt-only vs current authorization vs finite-state tool gate, независимый oracle на actual effect и owner consent, cost/latency.

**Research disposition:** P1_PROTOCOL_GATE_OFFLINE; associated candidate projects in [mapping](./2026-11-03-project-mapping-2026-10-27-to-11-02.md).

## 2. Goal-Aware Dynamic Multi-Agent Collaboration (GAD)

**Full primary source:** https://arxiv.org/abs/2610.39193 ; [PDF v1](https://arxiv.org/pdf/2610.39193v1) ; pages: 13 ; SHA-256: 5338392c1e65f133e460c8d33adf826872fb5fd45abdfb6240ee021762cfac93.
**Method/sample.** Динамический DAG многоагентных subtasks, сохранённые original goal/subgoal/acceptance conditions, раннее промежуточное verification. К каждому worker передаются только доказательства от выполненных dependencies, а не вся смешанная multi-agent история. Испытания Terminal-Bench 2.1 и SWE-bench Pro Hard-51, несколько backbones.

**Authors outcomes (not independent reproduction).** На Terminal-Bench 2.1 Claude Sonnet 4.6 GAD 71,9% против 65,2% у сильнейшего MAS baseline; Qwen3.7-Plus 64,0% против 57,3%. На SWE-Pro результаты тоже положительные для отдельных cells, но стоимость высока.

**Limits and confounders.** До трёх workers, большие лимиты calls, отдельный semantic verifier от LLM (не независимый test oracle), контекст и budget не всегда нормированы. Нельзя обещать эти выигрыши при другом времени/цене API, автономности и зависимости задач.

**Smallest falsifiable experiment.** 30–50 coding/research DAG tasks: existing team flow vs explicit acceptance conditions vs dependency-scoped evidence. Test/build oracle, false accepts, rereads, tokens, wall time and retries.

**Research disposition:** P2_ACCEPTANCE_DAG; associated candidate projects in [mapping](./2026-11-03-project-mapping-2026-10-27-to-11-02.md).

## 3. Your Policy Is Secretly a Harness — Decision Geometry

**Full primary source:** https://arxiv.org/abs/2610.37255 ; [PDF v2](https://arxiv.org/pdf/2610.37255v2) ; pages: 32 ; SHA-256: d678315eba5c30fd26966f6a33ea635b2889391b0d8eacc718f085063cea5319.
**Method/sample.** Разделение потенциального ceiling интерфейса agent harness и policy mismatch при KL-regularized control. MiniWoB++ эксперимент меняет порядок observation fields/representation при сохранении семантически допустимых действий. В Terminal-Bench Lite оптимальную policy приближают более сильным teacher model.

**Authors outcomes (not independent reproduction).** Для обученной Qwen3.5-2B одна перестановка полей опускала task success с 85,0% до 19,2% в контролируемой среде. Это специфический benchmark, не ожидаемый процент регрессии DSH; fixed-model comparison может недооценить потенциально лучший, но непривычный harness.

**Limits and confounders.** Идеальный ceiling обычно неизвестен, teacher proxy смещён; эффект зависит от обучающего harness, модели, способов сериализации и исходной policy. На практике нужен воспроизводимый A/B для любого prompt/tool schema изменения, но не новая теоретическая RL-рамка.

**Smallest falsifiable experiment.** 100 fixed model/tool tasks: неизменная LLM и tools, переставлять schema order, observation fields, prompt sections; repeated runs, task success, tool-choice drift, cached tokens, latency/IO.

**Research disposition:** P1_INTERFACE_REGRESSION_AB; associated candidate projects in [mapping](./2026-11-03-project-mapping-2026-10-27-to-11-02.md).

## 4. Where You Inject Matters — Trust Region Effect

**Full primary source:** https://arxiv.org/abs/2610.38867 ; [PDF v1](https://arxiv.org/pdf/2610.38867v1) ; pages: 21 ; SHA-256: 82473243e510b0a7fa305a92c73c619e15d91b276d224e00ea39413d2212d4d5.
**Method/sample.** Три sandbox agent testbeds для tool, coding, daily workflow; 36 разных untrusted surfaces и 24 категорий риска. Содержание synthetic injection фиксируется при смене размещения. Исследуются поведение агента, источник текста и позиция внутри документа; механизм поиска payload/placement не нужен для defensive adoption.

**Authors outcomes (not independent reproduction).** Авторы сообщают, что для GPT-5.4 coding tasks исполнение той же вредной инструкции из README/TODO приблизительно в 2,6 раза чаще, чем из code/data files. Успех зависит от поверхности; большинство неуспехов обусловлено игнорированием, а не явным защитным отказом.

**Limits and confounders.** Измерения на выбранных моделях, attacker objectives и containers; их результаты не доказывают реальную компрометацию AGENTS.md, source code или MCP output в наших текущих проектах. Placement-based heuristic не заменяет authority checks.

**Smallest falsifiable experiment.** 20–30 synthetic requests с одинаковым безвредным canary instruction в README/TODO/source/tool output; independent forbidden-effect oracle, read exposure, false accepts, legitimate utility; никакого реального вредного payload.

**Research disposition:** P1_DEFENSIVE_PLACEMENT_CORPUS; associated candidate projects in [mapping](./2026-11-03-project-mapping-2026-10-27-to-11-02.md).

## 5. Poisoned Skills — Agent Markdown Config Injection

**Full primary source:** https://arxiv.org/abs/2610.37738 ; [PDF v1](https://arxiv.org/pdf/2610.37738v1) ; pages: 6 ; SHA-256: c4c01de2f64be7228fee6864c6143fc36e12a68bb90ab3ad2b490bf79ac981f0.
**Method/sample.** Один LangChain QA agent собирает system prompt из загружаемого Markdown skill/config. Seven open-weight models, 270 forbidden questions по девяти категориям; сравнение benign vs tampered Markdown, а также обфускация zero-width и phonetic.

**Authors outcomes (not independent reproduction).** Средний ASR текстовых запрещённых ответов ~0,5% при benign prompt и 45% при tampered Markdown, до 68,9% для отдельных моделей; phonetic obfuscation снижала средний ASR до 30%. Это текстовый QA/JB outcome, не доказанный tool/privilege escalation.

**Limits and confounders.** Один framework и задачник, искусственная подмена trust artifact; подпись/hashing проверяет происхождение/целостность, но не содержательную безопасность. Работа не проверяет наших runtime guards и production mitigations.

**Smallest falsifiable experiment.** 20 benign fixture prompts/skills без вредного payload; version-controlled trusted allowlist, diff/review provenance checks, compare permitted behavior и unauthorized policy drift. No third-party package install.

**Research disposition:** P1_RULE_FILE_PROVENANCE; associated candidate projects in [mapping](./2026-11-03-project-mapping-2026-10-27-to-11-02.md).

## 6. Agent Transfer Protocol (ATP) — Server-Mediated Communication

**Full primary source:** https://arxiv.org/abs/2610.38398 ; [PDF v1](https://arxiv.org/pdf/2610.38398v1) ; pages: 12 ; SHA-256: 072f3943a10d1dfa6fa93d5932d8da9b5533b4d11ece905ba343a2a09e4843d5.
**Method/sample.** Кросс-организационные logical agent addresses и stable domain servers с durable receive queue; подписанный полный message envelope проверяется при получении и позднем чтении. Прототип проверял offline/restarted instance, delayed verification, message persistence и latency относительно direct HTTPS.

**Authors outcomes (not independent reproduction).** В travel coordination workflow offline/migration variants дали 5/5 успешных прогонов каждая. При keep-alive и in-memory filesystem на одном компьютере добавочная медианная latency двух domain servers около 2,7 мс относительно direct HTTPS. Это не WAN production SLA.

**Limits and confounders.** Синтетические domains и небольшое число сценариев; управление ключами, identity, revoke, queue retention, multi-host failure и cost/IO не проверены промышленным образом. Не путать этот академический prototype с отдельными draft ATP документов IETF; не внедрять transport без реального межорганизационного требования.

**Smallest falsifiable experiment.** При доказанном cross-org scenario: two disposable domain queues vs signed direct webhook, offline receiver restart, immutable envelope, revocation, latency/IO, duplicate/late delivery. Если межорганизационной потребности нет — NO_IMPLEMENTATION_NOW.

**Research disposition:** P2_CROSS_DOMAIN_ONLY; associated candidate projects in [mapping](./2026-11-03-project-mapping-2026-10-27-to-11-02.md).
