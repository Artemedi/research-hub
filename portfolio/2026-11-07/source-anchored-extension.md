## Эксперимент

Чистая закреплённая копия `Artemedi/dsh-paper2agent@6d82a42175a71d3327b773df88f1da0707efe43c`, реальный `App.import_research/import_projects/create_job/submit_analysis`. Текущую грязную рабочую копию целевого проекта не читали и не меняли. Восьми вручную выбранным абзацам соответствуют два дословных или достоверно перефразированных утверждения и два заведомо неподтверждённых/противоречащих, в частности: разница pair count и independent runs, когорты аннотаций, 154/357 machine judge agreement, роль структурных событий, одинаковые пять RQ2 trials, ограничения модели lifecycle и нулевой reward при crossing.

Исходный HTML каждого источника сверяется по SHA-256. Для `paper2project` строки абзацев нормализованы: **встроенные переносы строк HTML приводятся к пробелам**, иначе снимок документа ошибочно разбивает один абзац на несколько citation lines. Это поправка тестового *сценария*, не исправление целевого проекта. Привязка каждого цитируемого абзаца сохранена как source URL, ID раздела, хеш нормализованного абзаца и длина; тексты полных статей и исходные цитаты не коммитятся в публичный хаб.

**Рой:** `source_reviewer` и `counterexample_critic`, четыре последовательных пакета × две роли, checkpoint каждого role-run; все **8/8 COMPLETE**, 0 timeout, 32/32 согласованных решений, обе роли `glm-5.3-flash`. Прочитаны только избранные абзацы без авторских меток. Для новых 32 суждений: суммарное время модельных вызовов **116,48 с**, медиана 14,79 с, reported 6 468 input tokens, 5 967 output tokens, 6 912 cache-read input tokens. Совокупно на 64 claim: **253,72 с** на 16 модельных обращений, 12 476 input / 12 160 output / 14 464 cached input tokens. Это не стоимость в деньгах, не production latency и не статистическая выборка из научной литературы.

**Граница oracle:** метки истинности написаны исследователем заранее и не передавались ZCode. Они независимы от ответов модели, но **не являются слепой независимой человеческой разметкой**, тем более многократной экспертной adjudication. Оба агента используют одну модельную семью, поэтому единогласие не заменяет независимый контроль. Все 64 утверждения — **намеренно отобранные** локальные парафразы, точные цифры и отрицательные инверсии. Не проверены длинные сложные утверждения, многодокументные выводы, таблицы, статистическая интерпретация результатов, медицинские клинические выводы, таблицы со сносками и adversarial quoted content. `64/64` не даёт оценки частоты ошибок на естественном потоке запросов.

## Доказательства и вердикт

[Сценарий расширения](../../experiments/research-portfolio/2026-11-07-source-anchored-extension.py) (использует тот же [исходный runner](../../experiments/research-portfolio/2026-11-07-source-anchored-citation-ab.py), не дублируя код) / [машинные результаты и 32 case-level verdicts](../../data/results/research-portfolio/2026-11-07-source-anchored-extension.json). Перед запуском требуется легально получить **именно эти версии** двух полных HTML, сверить SHA, указать чистый source pin и ZCode wrapper. Временные документы и модельные checkpoints сохраняются за пределами публичного Git. Рабочий путь: Python с BeautifulSoup, локальный Git, изолированный `TempDirectory`, два независимых по контексту модельных вызова на пакет.

**Решение:** `ACCEPT_BOUNDED_FOUR_SOURCE_CITATION_AB`, `REWORK_INDEPENDENT_HUMAN_ANNOTATION`, `NO_NEW_FIT`, `NO_PRODUCTION_APPROVAL`. Для масштабирования требуется независимая слепая разметка нескольких сотен естественных claim↔evidence примеров с экспертной adjudication, реальными длинными источниками и равным бюджетом моделей; текущий узкий позитивный результат не оправдывает автоматизацию публикаций.
