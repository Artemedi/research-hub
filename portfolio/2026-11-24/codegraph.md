**Verified mechanism:** AST + native Rust/Tree-sitter extraction → symbol/import/call/route graph in local SQLite/FTS5 → MCP symbol search, impact and source context. [Install targets](https://github.com/colbymchenry/codegraph/tree/73c6cff66e525a92bff65675b6b0c46687e91ef1/src/installer/targets) include real DSH and Hermes target code. **Security caveats:** installer rewrites agent-home config; real indexed source snippets can enter external agent LLM context; anonymous telemetry **default-on** and GitHub update check violate literal no-network claim without explicit opt-out and OS deny. Watcher may be stopped/disabled, and answer freshness is bounded; graph misses dynamic SQL/reflection and isn't a SQL Server query plan/dependency analyzer. Don't install into live AKUZ/Hermes/DSH environment.

**Benchmark provenance:** [README](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/README.md) author reports 7-repo/4 runs per arm: 88% fewer tool calls, 62% fewer tokens processed, 44% cheaper, 53% faster on selected architecture questions. [37-cell language benchmark](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/docs/benchmarks/codegraph-ab-matrix.md): 76% fewer file reads but **$15.4 with vs $13.8 without**, and some tiny repos slower. [Three-turn retention](https://github.com/colbymchenry/codegraph/blob/73c6cff66e525a92bff65675b6b0c46687e91ef1/docs/benchmarks/residual-context-occupancy.md): ~80% **more residual retrieval context** with graph. Not independently repeated; no measured quality or savings on the user's repos.
