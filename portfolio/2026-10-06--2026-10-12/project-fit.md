## Критерии отбора и примечания

- Жирным выделен **первый кандидат** для исследования. Два-три проекта в строке не означают, что все требуют изменений: задача может оказаться межпроектным тестом без реализации.
- Вся матрица — предварительный **match по исследовательским профилям**, а не подтверждённый source-level `FIT_CANDIDATE`. Указанные выше конкретные проектные карточки и зафиксированный SHA — проверяемое обоснование *тематической связи*. Для перехода в `VERIFIED_FIT` нужно прочитать актуальный код целевого проекта, найти `repo@SHA/path:line`, выполнить baseline и повторяемый offline A/B.
- DSH разделён по ролям: `dsh` — control-plane, `dsh-runtime` — runtime, `HermesAgent` — gateway profile. Не предлагать вмешательство в один слой, если возможное владение находится в другом.
- Проект коллеги не получил ложноположительных сопоставлений по всем AI-статьям. В [его прежнем специальном ретроспективном обзоре](../2026-11-03/dotnet-retrospective.md) уже оценены прежде всего VeriHarness, Concordat и GeoAgent; они **не входят** в этот выпуск 6–12 октября. Точка интеграции для коллеги остаётся `NEEDS_SOURCE_CODE`.
- В публичном архиве сохраняются только названия, факт тематического соответствия и предполагаемый эксперимент. Ни закрытый исходный код, ни приватные architectural facts/production данные из каталога сюда не копировались.

## Минимальные проверяемые выходы следующего этапа

1. **HarnessSecurity-Bench + dsh-runtime:** независимый oracle реального эффекта и разрешённой операции, false deny/ASR, нулевой доступ к production.
2. **PackHallu + agent-config/agent-skills:** policy для исходника agent rules и изменяемых dependencies, oracle по безвредным manifests/lockfile, без атакующих payload.
3. **ExperienceIndex + Wiki_PG:** 50–100 запросов по разрешённому набору источников, gold recall@K, version-correct citations, полный индексный и online cost.

**Владельцу на решение:** `PENDING_OWNER_APPROVAL` для каждого офлайн-эксперимента. Отчёт не доказывает конкретные дефекты проектов и ничего не разрешает автоматически менять.
