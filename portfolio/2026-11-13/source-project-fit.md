# Drift Inspector и NVIDIA Auto Ontology — документальное соответствие проектам

**Дата 13.11.2026.** Источники: [Drift Inspector](../../studies/drift-inspector.md) и [Auto Ontology](../../studies/auto-ontology.md). Проверены проектные профили 45/45 карточек локальной копии project-registry (назначение/тип системы), актуальные исходники целевых проектов **не проходили source-level аудит**. Следовательно, таблица фиксирует только документально обоснованный shortlist и блокеры, не подтверждённый implementation seam или измеренную пользу. Нельзя копировать сюда приватные описания из профилей.

**Важно:** research-hub — главная workflow-цель Drift Inspector, но сам research-hub не является одним из 45 зарегистрированных project IDs; не создавать фиктивную project entity ради формального target. Journal Review — scheduled workflow, а не отдельный project ID.

| Drift Inspector | dsh-paper2agent | Профиль предусматривает импорт научного исследования и последующую оценку пригодности для конкретного проекта; ACC пригоден только для upstream discovery | Внешний extractor не проверен на проектном корпусе; полный текст обязателен; отдельный кодовый seam не установлен | Offline discovery на открытых 1–3 тыс. papers; full-text gate, 100–150 проверенных ACC, baseline BM25, recall@K/precision@K и false fit | PROFILE_MATCH_NEEDS_EVIDENCE |

| NVIDIA Auto Ontology | akuz-optimizer-twin | Профиль относится к структурам SQL Server, статистике и анализу планов; возможна описательная ценность связей схемы | Нет MSSQL connector; инструмент решает text-to-SQL, а не оптимизацию планов; direct implementation seam отсутствует | Вернуться лишь при появлении интерфейса экспорта и доказанной задачи семантической каталогизации (не production) | DEFERRED_NO_MSSQL_CONNECTOR |

Остальные 40 карточек project-registry: для этих двух тем на основании обзорных профилей прямой релевантный эксперимент не выявлен. Это **не 40 новых решений NO_FIT**: исходный код всех целей и задачи будущих пользователей не исследованы.

**Доказательный статус:** документальные PROFILE_MATCH / NEEDS_EVIDENCE и DEFERRED. Публикация не даёт ни A/B PASS, ни разрешения на внедрение. Статусы исследования, применимости к проекту и production authorization независимы.
