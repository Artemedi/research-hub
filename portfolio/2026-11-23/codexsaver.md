**Суть:** дешёвый specialist выполняет безопасный volume, Codex делает risk classification/final review. V1 model-proposed commands are run under `shell=True` without allowlist; v2 copies repository into tmpdir but runs allowlisted strings on host via shell; v3 `readonly` is mostly a prompt, Agent Cards include executable commands from workspace and HOME. This is **not** OS sandbox, so present design isn't acceptable for an untrusted codebase/DBA environment.
