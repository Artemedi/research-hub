# Research Hub

Научные и инженерные исследования для портфеля проектов: источники, обзоры, проверка применимости и воспроизводимые ограниченные опыты.

| Раздел | Содержимое |
| --- | --- |
| [Каталог исследований](catalog/studies/README.md) | Структурированные карточки: версии, обзоры, применимость и ограничения |
| [Проекты и исследования](projects/README.md) | Оценки применимости и их основания для 45 проектов |
| [Обзоры](reviews/README.md) | Подробные проверки одного источника, по датам |
| [Портфельные сводки](portfolio/README.md) | Выпуски и соответствие исследований проектам |
| [Коллекции](collections/README.md) | Происхождение подборок, включая Telegram-закладки |
| [Данные](data/README.md) | Результаты опытов и машинные матрицы применимости |
| [Эксперименты](experiments/README.md) | Скрипты, fixtures и условия воспроизведения |
| [Архив DSH](archive/dsh/ARCHIVE_MANIFEST.md) | Исторические копии с проверяемыми хешами |

Начните с карточки источника. Она ведёт к обзорам и ограничениям. Успешный опыт подтверждает только объявленные fixtures; он не доказывает безопасность всего инструмента, пользу проекта или готовность к production.

## Правила работы

[Исследовательский протокол](RESEARCH_POLICY.md) определяет требования к полным текстам, исходникам, измерениям и публикации. [Организация репозитория](docs/architecture.md) описывает расположение файлов, названия и добавление материалов.

[project-registry](https://github.com/Artemedi/project-registry) хранит сведения о проектах. Этот репозиторий хранит исследования. [paper2agent-index](https://github.com/Artemedi/paper2agent-index) — отдельный производный индекс, не источник истины для обзоров.

Старые адреса работают через [слой совместимости](reports/README.md). Навигация генерируется из [каталога](catalog/structure.json); проверка целостности — `node scripts/check.mjs`.

Секреты, персональные и медицинские данные, закрытый код, production-логи и полные защищённые тексты в архив не публикуются. Исследовательские оценки не заменяют решение владельца о внедрении.
