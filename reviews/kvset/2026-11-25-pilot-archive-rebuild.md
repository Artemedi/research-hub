# KVSET — проверка содержимого пилотного пакета Paper2Agent

**Результат.** Из закреплённых Git-объектов восстановлены все 36 записей исторического пакета. SHA‑256 каждой записи совпал с манифестом и отчётом приёмки. Полный SHA‑256 исторического ZIP не воспроизведён. Из двух попыток ни одна не подтвердила побайтовую идентичность архива.

[Протокол](../../experiments/kvset/2026-11-25-pilot-archive-rebuild-protocol.md) · [Скрипт](../../experiments/kvset/rebuild-pilot-archive.py) · [Машинный результат](../../data/results/kvset/2026-11-25-pilot-archive-rebuild.json)

| Проверка | Результат |
| --- | --- |
| Содержимое и уникальные пути в восстановленном ZIP | 36/36 SHA‑256 совпали, включая 24 файла авторского репозитория |
| Стандартный zlib 1.3.1, два одинаковых повтора | 89 924 байта, хеш отличается |
| zlib-ng 2.3.3, два одинаковых повтора | 87 664 байта, хеш отличается |
| Исторический ZIP, по двум сохранённым отчётам | 87 551 байт, SHA‑256 `cef186cc5b9a6bd52f58f7172e26c723aaf3fadf8e113ff04a9e9e14e369f766` |

Оригинал ZIP не найден в проверенных локальных каталогах, истории Git и среди файлов выпуска Paper2Project 1.0.1. Исторический манифест сборки сохраняет `PENDING`. Отдельный отчёт приёмки того же SHA‑256 содержит `PASS`. Эти документы фиксируют разные этапы работы. Текущая проверка подтверждает состав пакета и содержимое его файлов. Причина расхождения полного ZIP не установлена. [Манифест сборки](https://github.com/Artemedi/dsh-paper2agent/blob/6418c2397fd16a73cba58990fca2f6801e01148c/experiments/kvset/reports/package-inventory.json) · [Историческая приёмка](https://github.com/Artemedi/dsh-paper2agent/blob/6418c2397fd16a73cba58990fca2f6801e01148c/experiments/kvset/reports/delivery-validation.json)

У текущего checkout `c3bbe09bddf54b0efdcc0da1f17e1446dd35a4fd` один из десяти неизменяемых при упаковке файлов отличается от исторической версии: `run.py`. Два служебных JSON генерировались при сборке и сравнивались отдельно. Поэтому историческая приёмка пакета относится к пилотному набору байтов. [Научный обзор KVSET](2026-11-05-full-text.md)
