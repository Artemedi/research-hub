# REVA — сохранённые оценки фрагментов Wiki_PG

**Результат.** На 100 искусственных запросах лексический поиск и сохранённые оценки дали по 80 правильных фрагментов. Оценки добавили 20 попаданий для частых вопросов и потеряли 20 попаданий для вопросов о редком исключении с общей лексикой. Два прогона совпали.

[Протокол](../../experiments/reva/2026-11-26-wiki-pg-frozen-span-views-protocol.md) · [Скрипт](../../experiments/reva/wiki-pg-frozen-span-views.py) · [Данные](../../data/results/reva/2026-11-26-wiki-pg-frozen-span-views.json)

REVA повторно использует сохранённые оценки того, какие части документа нужны генератору. Стенд заменяет оценки внимания простым счётчиком выбора фрагментов в предварительных запросах. Штатный Wiki_PG подбирает кандидатов в явно указанном источнике. Три сравниваемых метода выбирают из них по одному фрагменту. [Статья REVA](https://arxiv.org/html/2609.11209v1)

| Сценарий | Первый подходящий по порядку | Штатное ранжирование | Сохранённые оценки |
| --- | ---: | ---: | ---: |
| Частый вопрос | 0/20 | 0/20 | 20/20 |
| Редкое исключение с общей лексикой | 0/20 | 20/20 | 0/20 |
| Точный запрос об исключении | 20/20 | 20/20 | 20/20 |
| Документ без сохранённых оценок | 0/20 | 20/20 | 20/20 |
| Изменившийся документ | 0/20 | 20/20 | 20/20 |
| **Всего** | **20/100** | **80/100** | **80/100** |

Оценка была привязана к пути, SHA‑256 и диапазону. При изменении хеша или пути скрипт использовал штатное ранжирование. Текст всех выбранных фрагментов совпал с указанными строками. Итог равен при равном весе искусственных сценариев. Для реального потока он зависит от доли частых и редких запросов. Вес внимания генератора, качество ответов, время и токены не измерялись.
