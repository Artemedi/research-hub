## Метод / результаты

StateComp обучает predictor по hidden-state признакам текущего agent state отмечать исторические взаимодействия, которые можно безопасно свернуть. Отдельные span-length и token gates решают, **когда** сделать summary; router-positive сам по себе не означает немедленную перезапись. На 260 WorkBuddyBench tasks общая награда авторов 0,6987 → 0,7026 (+0,0039 в шкале 0..1), суммарные agent+summary tokens **698,17M → 333,24M (−52,27%)**. На Security reward слегка падает с 0,4776 до 0,4731; нельзя объявлять систематический рост точности. Eval40 и cross-model замеры ограничены фиксированными наборами.

## Ограничения

Требуется скрытое состояние representation model и supervisor/annotation; доступность через закрытые API не гарантирована. Удалённый из активной истории текст не может быть автоматически восстановлен самим summary. Token reduction ≠ равная экономия денег/latency. Истинность приватных источников, сохранение доказательств, policy и rollback не исследованы локально.
