## Core method and original evidence

Separate target admission and text filtering. Egress floor looks for new recipient/resource/identity from untrusted tool results, compares to user's original task and approved typed tool return, applies deterministic delegation/authorization rules before side-effecting tool call. Ingress sanitizer removes agent-addressed instruction spans and forged model turn markers before exposing tool output. Optional local judge resolves limited ambiguous cases, not every request or an independent oracle. The proposed hard boundary is to check where a tool action goes, not merely ask a model if injection is safe.

In authors' **standard templated AgentDojo** evaluation (three backbones × 4 suites, 12 cells, total 2,847 attacked pairs), 0 in-scope target redirections observed; author 95% pooled one-sided upper confidence ~0.1% assumes independent pairs. Mean attack-time task utility 0.484, ~96% benign utility retained relative to undefended; baseline and competitors use specific configured routers/judges. Results do not generalize to arbitrary adaptive attacks, unrelated targets, high-risk SQL, or model versions. Under adaptive RL attacks authors report nonzero successes; ability to reference a legitimate named target and typed field spoofing are outside simple guarantees. Review the exact paper settings, not current default README settings.
