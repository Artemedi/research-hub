## Метод / результаты

VeriHarness разделяет two independent validation contexts: disagreement resolver проверяет спорные claims, consensus challenger ищет общую ошибку всех кандидатов. Решение привязано к доступным файлам/свидетельствам, не к большинству голосов; отдельная evidence-backed revision может исправлять выбранный артефакт. Авторы оценивали **10 rollouts на задачу** на пяти workspace benchmarks: selection улучшает single-rollout average на +4,4 п.п. для Gemini 3.5 Flash и +4,1 для Claude Opus 4.8, а после revision суммарный gain +6,2/+6,4 п.п. соответственно. Это авторские подсчёты при общем generation budget, не бесплатный verification. Обозначены ограничения same-model verifier, десяти rollout и дополнительной wall-clock latency.

## Ограничения

Модель проверяет evidence через tools, но надежность oracle может зависеть от прав доступа, полноты capture и сохранности файлов. Consensus не гарантирует правильность. Несколько подтверждений одним и тем же ошибочным инструментом не независимы. Локальный bounded code test прежнего отчёта не воспроизвёл эти цифры; для внешнего проекта коллеги нет source code/проверенного SHA.
