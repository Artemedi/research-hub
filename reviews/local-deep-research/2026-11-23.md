## 1. Evidence and architecture

- **VERIFIED — multi-stage research:** [README](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/README.md) and [langgraph_agent_strategy.py](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/src/local_deep_research/advanced_search_system/strategies/langgraph_agent_strategy.py) implement a LangGraph research agent, configurable focused-iteration and source-based modes, dynamic search across general web, arXiv, PubMed, user collections, library, then report synthesis. Web UI, local storage and MCP expose this; research results can be indexed for future use.
- **VERIFIED — citation indexing, not theorem-proof:** [standard_citation_handler.py lines 29–83](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/src/local_deep_research/citation_handlers/standard_citation_handler.py#L29-L83) formats retrieved document Title, URL and Content with numbered source indices and instructs LLM to cite indices. [LangGraph source collector](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/src/local_deep_research/advanced_search_system/strategies/langgraph_agent_strategy.py) tracks URLs, canonical dedup keys, snippets and library chunk anchors. This can make report URLs traceable, but a valid link does **not** prove a particular claim is supported by the passage, contains a valid exact quote, or reflects current and non-retracted science.
- **VERIFIED — model-scored source confidence:** [evidence/evaluator.py](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/src/local_deep_research/advanced_search_system/evidence/evaluator.py) asks an LLM for CLAIM, TYPE, SOURCE, CONFIDENCE, REASONING and QUOTE. Output numeric confidence is clamped to [0,1], and a simple string-token match heuristic adjusts it. This is **not a calibrated posterior probability or independent semantic entailment oracle**. Negation, conflicting evidence, duplicate studies and correct PMID/DOI mapping need external tests.
- **VERIFIED — local deployment ≠ fully offline:** [README](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/README.md) supports local Ollama/llama.cpp and external OpenAI, Anthropic, Google etc. SearXNG normally queries internet engines; search requests may leave even when inference is local. An apparently local OpenAI-compatible endpoint may proxy a cloud LLM. Don't advertise "fully private" without network isolation.
- **VERIFIED — storage encryption with caveats:** [SECURITY.md](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/SECURITY.md) documents per-user SQLCipher with password-derived key and encrypted API keys. Process memory still contains unlock material; default SQLCipher cipher_memory_security is OFF. Explicit development fallback LDR_BOOTSTRAP_ALLOW_UNENCRYPTED=true can use plaintext SQLite if SQLCipher fails; not for shared or sensitive use.
- **VERIFIED — egress policy is a guardrail:** [security/egress/policy.py lines 1–100](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/src/local_deep_research/security/egress/policy.py#L1-L100) explicitly says it is in-process and **NOT a hard security boundary**, cannot restrict compromised dependencies/in-process execution, and recommends firewall or network namespaces. [SECURITY.md](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/SECURITY.md) explains false-local proxy detection, DNS/SSRF protections and the privacy scope semantics. PRIVATE_ONLY is best effort, not offline proof.
- **VERIFIED — MCP trust boundary:** [mcp/server.py lines 1–32](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/src/local_deep_research/mcp/server.py#L1-L32) says **STDIO LOCAL USE ONLY**, without built-in auth/rate limiting for network exposure. Exposes quick/deep research, document retrieval, raw search, reporting and settings. Do not connect global MCP to confidential AKUZ/Hermes projects without separately approved isolation, scoped identities and outbound policy.
- **VERIFIED — deployment and operational cost:** [docker-compose.yml](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/docker-compose.yml) uses a floating :latest LDR image and default host port 5000:5000 (all interfaces); runtime drops to non-root after privileged volume setup and uses no-new-privileges/capability restrictions. Reproducible lab requires LDR image digest pin, localhost-only port binding or isolated interface, no production mounts, resource limits, and network policy. Large Python/Playwright/FAISS/PDF and model dependencies imply RAM, disk and cache costs; not a lightweight shell tool.
- **AUTHOR-REPORTED benchmark:** [README table](https://github.com/LearningCircuit/local-deep-research/blob/32b50c96f316e9025341fbf569c9381b8c9f351b/README.md#benchmarks) lists Qwen3.6-27B SimpleQA **287/300 = 95.7%**, xbench-DeepSearch **77/100**, Qwen3.5-9B **182/200**, gpt-oss-20B **295/346**. No independent result was reproduced; SimpleQA factual QA accuracy is distinct from citation faithfulness, clinical evidence grading or DBA forensic correctness.

## 2. Benefits, costs and risks

| Axis | Potential value | Required verification |
| --- | --- | --- |
| Academic discovery | Cross-engine search for PubMed, arXiv and existing docs | Full DOI/PMID URL and date provenance, retraction/duplicate detection and recall of counterevidence |
| Source-grounded claims | Source IDs and reusable indexed excerpts | Blind claim-to-passage audit, exact offsets, citation-ID coverage, fabricated/contradictory claims and negation tests |
| Persistent library | Searchable reusable documents | Encrypted storage audit and data life-cycle, no private corpus copied into cloud API prompts |
| Research productivity | Iterative query planning and report generation | Accepted verified sourced claims/operator-hour, latency p50/p95, reviewer work, tokens, CPU/RSS/VRAM and indexing IO |
| Local deployment | Self-hosted Ollama and search gateway | Network deny-egress proof; SearXNG upstream and proxy endpoints cannot be assumed to stay local |
| Agent workflows | MCP stdio research tool and UI | Trusted-only transport, no global hooks, isolated identity and workload-level policy review |

## 3. Pre-registered A/B/C — NOT EXECUTED

**H1:** on frozen public technical/scientific research questions, LDR improves independently verified source discovery/claim correctness per unit end-to-end work over incumbent source-bound review. **H0:** it merely yields more citations and costs more tokens, search calls, reviewer minutes and memory, with no verified gain.

- **A:** current research-hub/Paper2Project document-only workflow on pinned public technical papers and PostgreSQL references, with independent verification and original sources retained.
- **B:** LDR discovery-only (source titles/URLs/snippets) with public fixed corpus, no private library or tools, then existing independent scorer and reviewer. This isolates retrieval value from narrative hallucination.
- **C:** LDR full report on exact same public frozen questions in disposable lab; pinned provider/search/strategy, dedicated user and neutral local API endpoint, network isolation (for offline run pre-download corpus), independent source validator. **Separate owner/security gate before executing C**; no production AKUZ or patient data.
- **Fixtures:** 30 exploratory then >=100 pre-registered questions (including Russian technical queries), source contradictions, retractions, noisy citations, unavailable abstract, date changes, injected instructions inside retrieved webpages and false DOI/PMID, all with grounded gold passage or justified abstention. Fix seed/model/search/temperature/knowledge cutoff, paired randomized run order, >=5 repetitions when timings compared. Reviewers see anonymized outputs, not the system label.
- **Metrics:** source recall/precision, accepted claim correctness/grounding %, citations with exact supporting passage %, unsupported assertions, hallucinated citations, negative/abstain handling, independent reviewer minutes, end-to-end latency/cost/CPU/RSS/VRAM/disk footprint, external network destinations. 100% citation IDs resolvable is necessary but insufficient. Any sensitive outbound transfer => REJECT.
- **Promotion criteria:** measurable net benefit over A in **independent grounded correctness** at tolerable total resource/reviewer cost, verified no unauthorized network data egress, reproduced artifact/model/URL pin, and no bypass of Paper2Project source-bound judgement. Otherwise NO_BENEFIT / RESEARCH_ONLY.
