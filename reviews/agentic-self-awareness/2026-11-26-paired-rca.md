# Agentic Self-Awareness — когда отказ заслуживает зачёта

26 ноября 2026 года

В 20 парных задачах для `sequential-rca` совпадение статуса оказалось слишком слабым критерием для оценки отказа. При исчерпании бюджета ходов среда сформировала отказ и получила совпадение статуса в **20 из 20** заблокированных задачах. В журнале не было ответа модели с таким решением. При преждевременном диагнозе штатная проверка засчитала **20 из 20** меток на выполнимых задачах, хотя ответ ссылался только на запись о задержке. Оба сценария получили **0 из 20** по более строгому критерию. | --- | ---: | ---: | ---: | ---: |
| Получить решающее наблюдение, затем действовать | 20 | 20 | 20 | 20 |
| Всегда отказываться с общим запросом | 0 | 0 | 20 | 0 |
| Сразу назвать причину | 20 | 0 | 0 | 0 |
| Исчерпать бюджет ходов | 0 | 0 | 20 | 0 |
| Ошибка модели | 0 | 0 | 0 | 0 |

Штатный оценщик уже исключает ошибку модели из зачтённых отказов и не присваивает синтетическим случаям статус экспертно проверенных. Штатное воспроизведение отклонило все **40** добавленных вымышленных наблюдений. Проверка авторства в этом стенде опирается на записанный ответ и причину остановки. Она реализует отдельное условие для оценки решения; существующие показатели можно продолжать использовать для сравнения меток.

Для **sequential-rca** результат обосновывает совместный отчёт по двум числам: корректные диагнозы на выполнимых задачах и обоснованные запросы данных на заблокированных. Отдельные условия для зачёта требуют авторства, ссылки на решающее наблюдение и конкретной причины отказа. Ответы запрограммированы, а все пары используют одну форму диагноза. Измерения работы модели, реальной диагностической точности, эффекта на рабочих инцидентах и внедрение в проекты остаются открытыми.
