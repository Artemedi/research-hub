**Дата:** 2026-11-05. **Источник:** [Capture the Lifecycle, arXiv:2609.39819v1](https://arxiv.org/html/2609.39819v1), 30.09.2026. Изучены §§2–9, message-level primitives, state machine, оценка и ablations. SHA-256 HTML `d0c211ef0bc8cf6583ba7acb1b92b9609e0f44537062e7402a750d5e8a270bfb`.

## Метод и результаты

Agent harness экспонирует append/replace/remove/fork/spawn/one-off/pin/unpin context lifecycle. KV manager трактует message scopes и сохраняемость (live/suspended/discarded), а cache engine меняет eviction policy по семантическому статусу; это не обычное текстовое сжатие. На трёхузловом SGLang кластере с **12 GB200**, 1,2 TB RAM KV pool, KVTether снизил среднюю end-to-end latency на **16,5% против LMCache** и **12,4% против MORI**, авторская *estimated task pricing* — на 40,0%/33,2%; максимальные улучшения latency 26,3%/17,4%. В исходнике показано внедрение hooks в шесть harness (26–216 строк в авторской оценке).

## Ограничения

Нужны контролируемый inference runtime, реальные lifecycle signals, управление KV storage/eviction и масштабные serving traces. Цены смоделированы, а не продемонстрированы по нашим счетам. Нет измеренного source-level integration seam в текущем портфеле; через закрытый API-провайдер перехватить KV eviction нельзя. Тест на локальном сервере без тех же возможностей не докажет эффект.
