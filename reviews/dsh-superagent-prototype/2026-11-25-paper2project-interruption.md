# DSH Superagent Prototype — восстановление прерванной попытки Paper2Project

В восьми синтетических сценариях Paper2Project отличил живого владельца рабочей области от оставшейся записи `RUNNING`. После освобождения блокировки запись решения сохранила прерывание. Более поздняя успешная попытка добавилась в историю и дала итог `MIXED_EVIDENCE`. Два прогона дали одинаковые результаты.

## Контракт и опыт

Прототип DSH сохраняет состояние работы и при перезапуске передаёт исполнителю сведения для восстановления. Его документация отдельно описывает перепроверку перед повторением внешнего действия. В Paper2Project проверили более узкое свойство: что происходит с незавершённой попыткой при повторном открытии SQLite и записи решения. [Документация прототипа](https://raw.githubusercontent.com/deepseek-ai/dsh-superagent-prototype/8c32a9dc5d72c033816c6a8110b37f40cf94fba4/docs/003-execution.md) · [Предыдущий опыт](2026-11-05.md)

Использовали `dsh-paper2agent@c3bbe09bddf54b0efdcc0da1f17e1446dd35a4fd`. Отдельный процесс открывал временное хранилище и держал штатную `flock`. В четырёх сценариях процесс закончил работу штатно, в четырёх был завершён при удержании блокировки. Половина записей содержала результат только первой ветки. Последующую завершённую попытку добавляли как отдельную искусственную запись с проверяемым результатом.

| Проверка за прогон | Результат |
| --- | ---: |
| При живой блокировке отчёт показал `RUNNING`, а запись решения отказалась | 8/8 |
| После выхода процесса отчёт показал `INTERRUPTED`, а исходная строка SQLite ещё имела `RUNNING` | 8/8 |
| Запись решения зафиксировала прерывание и сохранила исходный набор результатов | 8/8, в том числе 4 с частичным результатом |
| Поздний `PASS` оставил обе попытки в истории и дал `MIXED_EVIDENCE` | 8/8 |
| Повторные записи решения не создали дублей, новая запись ссылается на прежнюю | 8/8 |

Для повтора в Linux или WSL передать путь к чистой закреплённой рабочей копии команде `python -B experiments/dsh-superagent-prototype/paper2project-interruption.py CHECKOUT`. Опыт выполнен на Python 3.12.16.
