## Метод / результаты

Paper2Agent превращает публикацию и reference code в проверяемые MCP инструменты через шестиэтапный multi-agent pipeline: обнаружение исходников, извлечение вызываемых API, генерация wrappers, тестовые fixtures, исправление расхождений, публикация tool surface. Источник не становится корректным только потому, что LLM создала интерфейс; результат проверяется повторением примеров оригинального кода. На 100 computational biology papers в авторской оценке **74 удалось agentify**, предложено 599 tools, **593 прошли авто-валидацию**; шесть не прошедших не должны стираться из знаменателя. На отдельном 300-question tutorial benchmark указаны 91,2 ±1,6% у Paper2Agent/Sonnet 4 против 80,3 ±2,3% прямого Claude+Repo с тем же Sonnet 4. Это результаты авторов, не проверка наших плагинов.

## Ограничения

Для части статей отсутствуют запускаемый код, datasets или модели; авто-валидатор может пропускать смысловые ошибки за пределами reference fixtures. Научные эксперименты и биологические результаты нельзя автоматически считать валидированными после построения MCP. Нарушение лицензии/публикация чужих данных и небезопасное исполнение сгенерированных команд — отдельные угрозы. Никаких исходных методов и научных данных не скачивали и не запускали.
