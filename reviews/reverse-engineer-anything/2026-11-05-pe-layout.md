05.11.2026 сверены HEAD и локальный checkout [morluto/rea@92f332652d352e60b550567adf2399d83d8ebe78](https://github.com/morluto/rea/tree/92f332652d352e60b550567adf2399d83d8ebe78), package 6.8.0. От предыдущего SHA изменились 45 файлов; parser fixture запускает текущую ревизию. Лицензия MIT, отдельные third-party notices сохраняются. Это не разрешение на анализ произвольных чужих бинарников.

Дополнительно прочитаны ManagedStaticProvider dispatch и metadata, ManagedSnapshot admission/identity, BoundedFileBytes, весь ManagedPeReader и его domain dependencies; выборочно ManagedArtifactInspector/tests, ManagedMemberInspector, ManagedMetadataLayout, ManagedDecodeBudget и reconstruction service. Это углублённый обзор **static managed пути**, не построчный аудит всех native, browser, ADB, Frida и MCP подсистем большого репозитория. `FULL_REPOSITORY_SECURITY_AUDIT` не присвоен.

[ManagedPeReader.ts:192](https://github.com/morluto/rea/blob/92f332652d352e60b550567adf2399d83d8ebe78/src/dotnet/ManagedPeReader.ts#L192) проверяет пересечение sections перед преобразованием RVA; виртуальная область без file backing не должна становиться читаемыми metadata. [ManagedSnapshot.ts:31](https://github.com/morluto/rea/blob/92f332652d352e60b550567adf2399d83d8ebe78/src/dotnet/ManagedSnapshot.ts#L31) ограничивает вход 128 MiB. Это не предел общего RSS. Digest/MVID и build-local tokens надо сохранять вместе; одинаковое имя метода не удостоверяет идентичность. Unsupported/partial metadata и отсутствие найденного member — разные результаты. Reconstruction остаётся inference, не восстановленным и проверенным исходным C#.

Static provider не загружает анализируемую assembly в CLR для исполнения. Однако effect annotations и локальные capability bridges **не являются OS isolation**: внешние providers, динамические команды и вызывающий model agent имеют отдельные полномочия и каналы данных. Здесь они не запускались.

## Воспроизводимый опыт

[Авторский fixture](../../experiments/2026-11-05-bk062-pe-layout.mjs), [машинный результат](../../data/results/reverse-engineer-anything/2026-11-05.json). Node 24.19.0 исполняет оригинальный TypeScript reader через transform-types и относительные import hooks, без npm install. Проверить checkout SHA до запуска. Пример из корня hub, SOURCE — абсолютный путь отдельного checkout:

```sh
node --experimental-transform-types --permission --max-old-space-size=128 \
  --allow-fs-read="$SOURCE" \
  --allow-fs-read="$PWD/experiments/2026-11-05-bk062-pe-layout.mjs" \
  experiments/2026-11-05-bk062-pe-layout.mjs "$SOURCE"
```

Fixture самостоятельно строит 4096-byte PE32/PE32+ header buffers. Независимый oracle — заданные file offsets, architecture и refusal expectations, а не копия reader output. Восемь семейств × две разрядности × три повтора: **48/48 PASS**. Проверены valid metadata coordinates, bad MZ, truncated sections, отсутствующий directory count, overlapping sections, unbacked virtual RVA, short CLI header и out-of-range RVA. Это структурные buffers, не доказательство CLR-loadable assembly или корректного CIL.

Negative control: в отдельной копии единственный `if (intersects)` заменён на `if (false && intersects)`. Тот же fixture завершился assertion failure: overlapping input получил CLI layout вместо отказа. Original checkout не изменён. Baseline — известная структура и отказ на negative twins; не сравнение производительности с другими RE tools.

FS read allowlist и Node permission mode запрещают сетевой доступ и дочерние процессы; heap cap 128 MiB — не абсолютный RSS cap. Входы в памяти, нет дисковой записи fixture и реальных binaries. Полный upstream tests/lint/build **NOT_RUN**: dependency-complete package environment не готовился. Успешный запуск original reader не заменяет typecheck, весь metadata/CIL pipeline, adversarial fuzzing или target benchmark. Latency/IO/RSS и экономия труда не измерены.
