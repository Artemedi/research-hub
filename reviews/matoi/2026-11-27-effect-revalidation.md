# Matoi × DSH Runtime — повторная проверка последствий и разрешений

27 ноября 2026 года

В каждом из трёх повторов выборочный пересчёт сократил число расчётов с 44 до 28, включая первоначальное заполнение кеша. Обе ветки дали одинаковые результаты во всех 24 сценариях с конкретными входами. Каждая выполнила 44 запроса к штатному сервису разрешений DSH Runtime и 36 вызовов вымышленного инструмента. [Протокол](../../experiments/matoi/2026-11-27-effect-revalidation-protocol.md) · [Данные](../../data/results/matoi/2026-11-27-effect-revalidation.json)

| Сценарий, четыре входа | Итог второй попытки в обеих ветках |
| --- | --- |
| Входы прежние | Результат подтверждён |
| Изменилась вспомогательная метка | Результат подтверждён |
| Изменилось значение, от которого зависит результат | Результат пересчитан и подтверждён |
| Политика разрешений переключена в `never` | Штатный сервис отклонил запрос |
| Ответчик недоступен | Штатный сервис вернул `unavailable`, вызов не состоялся |
| Подтверждение первой попытки отсутствует, идентификатор тот же | Журнал стенда сохранил неизвестный исход и заблокировал повтор |

Каждый новый запрос заново проходит штатную проверку разрешения. Скрипт сверяет отдельную пару аудиторских событий с идентификатором запроса и решением. Результат зависит от явно заданного арифметического правила. Блокировка повтора проверена на журнале стенда в памяти. Сохранность при сбое процесса, состояние внешнего получателя и время исполнения остаются за границей измерения.
