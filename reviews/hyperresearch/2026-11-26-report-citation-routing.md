# Hyperresearch 0.13.3 — какие цитаты доходят до проверки

26 ноября 2026 года

В каждом формате ссылок Hyperresearch 0.13.3 автоматически принял **36 из 72 неподтверждённых утверждений**. Полная выборка пар, уже помеченных для проверки, оставила те же 36 за пределами очереди. Вариант с точным совпадением отправил на проверку **все 72**. Он также отправил 12 корректных перефразировок. Во всех режимах отдельная ссылка без источника была помечена как проблема. [Протокол](../../experiments/hyperresearch/2026-11-26-report-citation-routing-protocol.md) · [Данные](../../data/results/hyperresearch/2026-11-26-report-citation-routing.json)

| Режим | Неподтверждённые утверждения приняты автоматически | Размер очереди для нумерованных ссылок | Размер очереди для ссылок на заметки |
| --- | ---: | ---: | ---: |
| Штатная выборка | 36 из 72 в каждом формате | 48 | 43 |
| Полная выборка из пар, помеченных для проверки | 36 из 72 в каждом формате | 48 | 48 |
| Точное совпадение и проверка остальных пар | 0 из 72 в каждом формате | 84 | 84 |

В автоматическую группу попали смена порядка событий, пропуск условия и отрицание исходной фразы. Штатные подсказки dsh-paper2agent отметили пропуск условия и отрицание, а также смену единицы и вымышленное утверждение вне темы источника. Смену порядка событий и числового значения они пропустили. Проверялась только функция подсказок, без итогового отчёта dsh-paper2agent. [Карточка dsh-paper2agent](../../projects/dsh-paper2agent.md)

Скрипт проверял фактический путь от Markdown до файла очереди Hyperresearch. Три прогона совпали. Нормализованное совпадение в этом стенде опирается на заранее верные заметки. Реальная заметка может потерять контекст, а совпадение текста само по себе не проверяет надёжность источника. Прежний запрет на автоматическое подтверждение по совпадению фрагмента остаётся обоснованным для проверенной версии.
