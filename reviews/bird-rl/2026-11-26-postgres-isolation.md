# BIRD-RL — изоляция последовательных задач в PostgreSQL

26 ноября 2026 года

На PostgreSQL 18.7 отдельный экземпляр и клон чистого шаблона начинали с исходного состояния в **6 из 6** прогонов каждого варианта. При повторном использовании одной базы одного отката хватило только для **2 из 6** чистых стартов. Строки и тестовая таблица восстановились, но `nextval` выдал 1, 2 и 3 в каждом запуске. Это штатная семантика PostgreSQL. [Протокол](../../experiments/bird-rl/2026-11-26-postgres-isolation-protocol.md) · [Результат](../../data/results/bird-rl/2026-11-26-postgres-isolation.json) · [Функции последовательностей](https://www.postgresql.org/docs/18/functions-sequence.html)

| Способ | Чистые старты в двух запусках | Медиана подготовки в каждом запуске | Медиана WAL рабочей транзакции |
| --- | ---: | ---: | ---: |
| Новый экземпляр | 6/6 | 2,14 и 2,28 с | 8 624 байта |
| Клон готового шаблона | 6/6 | 178 и 195 мс | 8 624 байта |
| Откат в готовой общей базе | 2/6 | 0 мс отдельной подготовки | 8 184 байта |

Время нового экземпляра включает инициализацию и заполнение. Время клона отсчитывается после подготовки шаблона. Шаблон сохранил эталонное состояние. Копирование также создавало WAL: около 5,85 МБ на клон в первом запуске. Три сохранённых клона вместе с шаблоном и системными файлами заняли около 78 МБ в каталоге данных. В JSON есть счётчики операций PostgreSQL и снимки памяти контейнера. Для сравнения физического ввода-вывода нужен стенд с диском. [Стратегии копирования PostgreSQL](https://www.postgresql.org/docs/18/sql-createdatabase.html)

Для **akuz-schema-inventory** результат обосновывает отдельную базу на тест, если тест меняет DDL или состояние последовательностей. Для **sequential-rca** тот же подход подходит для искусственных источников свидетельств, которые меняют состояние между шагами. Клоны проверены для последовательного выполнения в одном экземпляре. Отдельные права, параллельное исполнение, аварийное восстановление и эффект на проектах остаются открытыми. Стенд переносит вопрос об изоляции из BIRD-RL на PostgreSQL.
