# MCP Toolbox и Wiki_PG — живое значение и снимки PostgreSQL 15/18

**Результат.** На PostgreSQL 15.20 и 18.3 Toolbox показал все три изменения `work_mem` и совпал с прямым чтением базы. Wiki_PG на каждом этапе вернул те же два зафиксированных значения и сохранил даты и файлы снимков. Для даты между снимками он вернул `no_snapshot`. Два прогона совпали.

[Протокол](../../experiments/mcp-toolbox-postgres/2026-11-25-wiki-pg-temporal-contract-protocol.md) · [Скрипт](../../experiments/mcp-toolbox-postgres/wiki-pg-temporal-contract.py) · [Данные](../../data/results/mcp-toolbox-postgres/2026-11-25-wiki-pg-temporal-contract.json)

| Наблюдение | Результат за два прогона |
| --- | ---: |
| Toolbox совпал с прямым запросом к PostgreSQL по значению и единице | 12/12 |
| Wiki_PG вернул установленное значение, дату захвата и файл для указанной даты или последнего снимка | 36/36 |
| Wiki_PG вернул `no_snapshot` для отсутствующей даты без ошибки MCP | 12/12 |

Последовательность живых значений составила 4096 → 8192 → 16384 kB. Последний снимок оставался на 8192 kB. Снимки подготовлены заранее из констант стенда. Для живого значения эталоном был отдельный прямой запрос под той же ролью; она начинала сессию в режиме только чтения. Использованы реальные MCP-серверы через stdio.
