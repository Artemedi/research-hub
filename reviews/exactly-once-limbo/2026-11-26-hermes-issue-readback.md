# LIMBO × HermesAgent — когда сверка предотвращает повторную публикацию

26 ноября 2026 года

В **300 синтетических случаях на вариант** обязательный URL исходного видео убрал 60 дублей из 120. Все 60 устранённых дублей относились к случаю, когда первая задача была видна при повторе, но её текст не содержал URL. Когда первая задача оставалась скрытой, обе ветки создавали дубли в 60 из 60 случаев. Пропущенных публикаций в стенде не было. Два полных прогона дали одинаковый JSON. [Протокол](../../experiments/exactly-once-limbo/2026-11-26-hermes-issue-readback-protocol.md) · [Данные](../../data/results/exactly-once-limbo/2026-11-26-hermes-issue-readback.json)

| --- | ---: | ---: |
| Создание подтверждено | 0 | 0 |
| Ошибка до создания | 0 | 0 |
| Ответ потерян, задача с URL видна | 0 | 0 |
| Ответ потерян, задача без URL видна | 60 | 0 |
| Ответ потерян, задача пока скрыта | 60 | 60 |

Тест исполнял функции анализатора, сверки и публикации из закреплённой версии HermesAgent. Список задач и журнал фактически созданных записей в подставном сервисе разделены. Генерация текста и подбор видео заменены фиксированными данными. Работа не определяет частоту таких отказов, предел задержки видимости GitHub или поведение при параллельных запусках. Вывод статьи о пределах повторной сверки согласуется с наблюдением на этой модели.
