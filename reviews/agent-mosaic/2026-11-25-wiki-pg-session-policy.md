# Agent Mosaic — контроль составных сравнений Wiki_PG

В 28 синтетических сессиях проверка каждого ответа отдельно остановила четыре запрещённых сочетания. Ещё восемь сочетаний появились в раздельных ответах одной сессии. Лабораторное правило, которое учитывает уже выпущенные поля, остановило все 12 сочетаний и сохранило 20 разрешённых выдач. Два прогона дали одинаковую сводку.

## Что проверили

Статья предлагает отслеживать составные выводы при чтении данных и выпуске ответов. [Предыдущий опыт](2026-11-07-composite-gate.md) проверял независимую модель. Здесь источник фактов — штатный `compare_system_states` Wiki_PG, вызванный через отдельный read-only MCP stdio. [Agent Mosaic, §7](https://arxiv.org/html/2610.30418v1#S7) · [Wiki_PG, сравнение снимков](https://github.com/Artemedi/Wiki_PG/blob/d55721bb99bff25fae352341cfd630c048693d6b/Wiki_PG/ingestion/system_queries.py#L492-L631)

Штатное сравнение возвращает вычисленную разницу и ссылки на обе стороны. Стенд проверял ID, время и хеш двух искусственных снимков, а на выходе оставлял только запрошенные ключи и числовые разницы. Тестовая политика разрешала показывать изменение памяти и изменение числа CPU по отдельности. Их сочетание для одного вымышленного хоста в одной сессии запрещалось. Изменение времени работы служило разрешённым контролем. Независимая проверка читала исходные JSON, пересчитывала разницы и проверяла поля, фактически выпущенные за сессию.

| За 36 попыток выдачи в 28 сессиях | Только проверка источников | Правило для ответа | Правило для сессии |
| --- | ---: | ---: | ---: |
| Выдано ответов | 32 | 28 | 20 |
| Остановлено правилом | 0 | 4 | 12 |
| Неполное происхождение, выдача остановлена | 4 | 4 | 4 |
| Сессий с обоими защищёнными полями на выходе | 12 | 8 | 0 |

Каждый прогон получил 16 нативных ответов для четырёх вымышленных хостов. Три подхода использовали эти же ответы. Хеш SQLite сохранился. Для повтора нужны Linux или WSL, чистая версия Wiki_PG `d55721bb99bff25fae352341cfd630c048693d6b` и закреплённые зависимости `mcp==1.28.1`, `PyYAML==6.0.3` и `requests==2.34.2`. Сценарий выполнен на Python 3.12.16.
