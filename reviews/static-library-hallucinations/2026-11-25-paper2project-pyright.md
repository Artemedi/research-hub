# Static library hallucinations — предупреждения Pyright на вызовах Paper2Project

**Дата:** 25.11.2026. **Результат:** `SYNTHETIC_SCREENING_PASS / BENEFIT_UNPROVEN`. Pyright нашёл 16 из 16 прямых ошибок API до запуска и пропустил все восемь ошибок в динамических вызовах. Корректные вызовы предупреждений не получили.

## Основание

[Статья Miranda-Pena и соавторов, arXiv:2604.07755v3](https://arxiv.org/pdf/2604.07755v3) различает наличие предупреждения и диагностику по правильной причине. Продолжение [полнотекстового обзора от 14 ноября](2026-11-14.md) проверяет это свойство на вызовах живого API приложения. Оригинальный PDF импортирован с SHA-256, совпавшим с зафиксированным в обзоре. Локальное задание `job-b83e4bb81f3646cb` приняло точные цитаты из оригинала и карточки проекта и вернуло `ANALYSIS_ONLY`.

`dsh-paper2agent` — ID проекта в [реестре](https://github.com/Artemedi/project-registry/blob/91a0ca742a3225f6c4683b51031e8bbb595fdab8/projects/06-independent-research/dsh-paper2agent/PROJECT.md), который описывает Python-конвейер и CLI/MCP. Для опыта использована выделенная [реализация Paper2Project на 57991e6](https://github.com/Artemedi/paper2project/tree/57991e6681ad683a5be8111b7d470fed5d53625b). Вызовы работают с настоящим классом App и временными хранилищами. [Импорт, создание и чтение задания](https://github.com/Artemedi/paper2project/blob/57991e6681ad683a5be8111b7d470fed5d53625b/src/paper2project/core.py#L149-L234) · [Статус и отчёт](https://github.com/Artemedi/paper2project/blob/57991e6681ad683a5be8111b7d470fed5d53625b/src/paper2project/core.py#L493-L525).

## Опыт

[Протокол](../../experiments/static-library-hallucinations/2026-11-25-protocol.md) зафиксировал 40 вызовов восьми методов. Синтаксически корректный вызов запускался в реальном приложении с искусственными входами. Для ошибочных случаев класс исключения и имя метода или аргумента должны были совпасть с ожидаемыми. На этапе до запуска сравнивались компиляция Python и она же с добавлением Pyright 1.1.407. Проверка проводилась локально в WSL, без запроса модели и исполнения кода авторов.

| Вариант на один повтор | Вызовов | Pyright предупредил по нужной причине | Runtime подтвердил ошибку |
| --- | ---: | ---: | ---: |
| Корректные прямые и динамические вызовы | 16 | 0 | 0 |
| Несуществующий прямой метод | 8 | 8 | 8 |
| Неизвестный именованный аргумент | 8 | 8 | 8 |
| Несуществующий метод через getattr | 8 | 0 | 8 |

Все три повтора дали одинаковые счётчики. Компиляция Python приняла все 40 файлов. Медианное время на пакет из 40 проверок: компиляция 4,72 мс, Pyright 1 427,38 мс, тестовые вызовы приложения 26,31 мс. Время включает запуск Pyright отдельным процессом и относится к коротким примерам. Память не измерялась. Измерение поддерживает использование статического анализа как дополнительного предупреждения, а тесты исполнения остаются обязательными для динамических вызовов. На этом наборе само предупреждение было значительно дороже короткого локального выполнения. Выгода возможна, если оно позволяет избежать достаточно дорогого или нежелательного запуска. Исходный код продукта и его конвейер исполнения не менялись, контейнерный опыт внутри задания не регистрировался.
