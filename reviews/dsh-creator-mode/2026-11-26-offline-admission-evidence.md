# DSH Creator Mode — проверяемость офлайн-результата

**Результат.** Пять штатных тестов `agent-skills` прошли. Они проверяют каталог и контракт навыков. Проверка сохранённого опыта связала исходник и манифест с отчётом о девяти проверках. Во всех 14 отрицательных контролях изменённый набор сведений был отклонён. Пригодность к живому Creator-прогону остаётся открытой.

| Проверка | Наблюдение |
| --- | --- |
| `agent-skills@8170c5f` | 5/5 штатных тестов. Закреплённый каталог включает 16 навыков. Отдельной приёмки Creator-плагинов в этом каталоге нет |
| Сохранённый офлайн-опыт | Хеши исходника и манифеста совпали. В записи присутствуют все 9 проверок, включая очистку и отсутствие Slot |
| Отрицательные контроли | Два одинаковых набора из семи изменений. Хеши, полнота проверок, заявленная область и зафиксированный режим изоляции проверяются отдельно |
| Манифесты DSH | `dsh-runtime@b6a1635` объявляет `0.1.5-alpha.1` для CLI и desktop. Версия развёрнутой среды не установлена |

Штатные тесты каталога дают воспроизводимую основу для хранения будущей процедуры, а проверка исторического отчёта даёт отдельный контроль переноса доказательств. Она сверяет записанные результаты и границы. Девять проверок плагина здесь заново не исполнялись. Манифест исходной ветки содержит версию новее порога исправления в официальном уведомлении. Из манифеста нельзя подтвердить наличие исправления в фактически используемом бинарнике.
