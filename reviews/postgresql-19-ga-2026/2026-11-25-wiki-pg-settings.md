# PostgreSQL 19 — версионная диагностика настроек I/O в Wiki_PG

**Дата:** 25.11.2026. **Результат:** `SYNTHETIC_TRANSFER_PASS / BENEFIT_UNPROVEN`. Текущий парсер Wiki_PG сохранил числовую версию, порт и значения настроек для всех 30 искусственных снимков. Пробная классификация поверх этих данных совпала с эталоном 150 из 150 раз в каждом из трёх повторов.

## Источник и код

[Официальные release notes PostgreSQL 19](https://www.postgresql.org/docs/19/release-19.html), E.1.2 и E.1.3.1.2, описывают замену `io_workers` четырьмя настройками управления I/O workers. Проверка сужает [портфельную гипотезу от 23 ноября](../../portfolio/2026-11-23/review.md) до возможности различать версии и пропуски в диагностическом снимке. SHA-256 локального HTML, импортированного в Paper2Project, составляет `0a80486df4b6714d349b15188496bc10751228ee7c478a8c802a9e88d09c86e6`. Локальное задание `job-824aa8ac19f54098` приняло цитаты из release notes и карточки проекта. Отчёт указал `HTML_TEXT_ONLY` и `ANALYSIS_ONLY`.

В [карточке Wiki_PG на 91a0ca7](https://github.com/Artemedi/project-registry/blob/91a0ca742a3225f6c4683b51031e8bbb595fdab8/projects/01-dba-akuz/Wiki_PG/PROJECT.md) заявлена диагностика PostgreSQL. На актуальной ревизии `d55721bb99bff25fae352341cfd630c048693d6b` проверены места, где парсер отдельно записывает настройки и версию для каждого порта, а хранилище добавляет источник и его хеш. [Парсер Wiki_PG](https://github.com/Artemedi/Wiki_PG/blob/d55721bb99bff25fae352341cfd630c048693d6b/Wiki_PG/ingestion/structured_metrics.py#L120-L153) · [SQLite writer](https://github.com/Artemedi/Wiki_PG/blob/d55721bb99bff25fae352341cfd630c048693d6b/Wiki_PG/ingestion/metrics_store.py#L73-L146).

## Опыт

[Протокол](../../experiments/postgresql-19-ga-2026/2026-11-25-protocol.md) зафиксировал шесть типов синтетических снимков, пять наблюдений каждого типа. Парсер и SQLite записывали факты штатным способом. Пробный слой читал сохранённые строки и классифицировал пять настроек по наблюдённой версии того же порта. Снимки с отсутствующей версией или неполным списком настроек проверялись отдельно от версионной несовместимости.

| Метрика на повтор | Результат |
| --- | ---: |
| Снимки с точными значениями, портами и SHA-256 | 30/30 |
| Совпадение статуса с эталоном | 150/150 |
| Настроек с пропуском сбора | 15 |
| Настроек с неизвестной версией | 25 |
| Настроек, противоречащих указанной версии | 5 |
| Снимки со смешанными портами, поймавшие намеренно снятый фильтр порта | 5/5 |

Медианное суммарное время на 30 малых снимков составило 188,30 мс для парсинга, записи и чтения SQLite и 0,30 мс для дополнительной классификации. Это замер стенда на Windows 3.11.9 с пустой временной БД.
