# GAD × DSH Runtime — запуск зависимой задачи после проверки результата

26 ноября 2026 года

В **32 из 48 случаев** штатная доска разрешала взять дочернюю задачу, хотя результат одного из родителей отсутствовал, был неверным, относился к другой задаче или устарел. Внешняя проверка отклонила все 32 случая и разрешила запуск после исправления. Штатный путь и вариант с проверкой приняли все восемь случаев с корректным результатом. Ещё в восьми случаях сама доска блокировала запуск до завершения родителя. Три повтора дали одинаковые счётчики. [Протокол](../../experiments/goal-aware-dynamic-collaboration/2026-11-26-dependency-acceptance-protocol.md) · [Данные](../../data/results/goal-aware-dynamic-collaboration/2026-11-26-dependency-acceptance.json)

| Сценарий, восемь случаев каждый | Запуск через доску | Запуск с проверкой |
| --- | ---: | ---: |
| Оба результата корректны | 8 | 8 |
| Результат отсутствует | 8 | 0 |
| Неверное значение | 8 | 0 |
| Верное значение от другой задачи | 8 | 0 |
| Верная сумма из старой версии после повторного завершения | 8 | 0 |
| Один родитель ещё в работе | 0 | 0 |

Статья предусматривает проверку результата перед его передачей зависимым узлам. Здесь исполнены штатные переходы доски на закреплённом коде и отдельная лабораторная проверка сумм. Доска показала ожидаемую проверку полномочий и статусов. Внешняя проверка подтверждала содержимое, принадлежность к родителю и номер его версии. Это продолжает предыдущий эксперимент с проверкой структуры графа. Агентные сессии, модель, постоянное хранилище и приёмка корневой цели в этот прогон не входили.
