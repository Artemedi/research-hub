# Коллекции источников

Коллекция сохраняет происхождение списка материалов. Её записи могут ссылаться на один источник и иметь разные ограничения доступа. Коллекция не заменяет карточку исследования.

- [Telegram — восстановленные закладки](telegram/README.md): реестр, статусы, дубликаты и доступность; не дословный экспорт Telegram.
- [Архив DSH](../archive/dsh/ARCHIVE_MANIFEST.md): исторические копии с pinned revision и хешами.

Обзоры и актуальные оговорки находятся в [каталоге исследований](../studies/INDEX.md).
