# Завершение нормализации каталога

Базовая версия перед переносом оставшихся 74 карточек: `9c3c579989f5c7fa61d3eaa43239cbe28142d5a0`. Итог: **81/81 карточек нормализованы, legacy-очередь пуста**. Перенесены существующие материалы; новая научная экспертиза, production-интеграция и повторный запуск опытов не проводились.

## Что представлено в модели

| Область | Охват |
| --- | --- |
| Источники | 81 Study: 51 paper, 27 engineering, 1 недоступное видео, 2 technical disclosures |
| Проекты | 45 публичных проекций канонических карточек приватного реестра |
| История применимости | 450 Assessment records, 360 явных current pointers |
| Полные исходные матрицы | 270 строк JSON, включая историю REA и Desktop; 4 источника с покрытием MIGRATED |
| Документальные связи | 180 точных оценок из существующих таблиц и текста; 73 источника с покрытием PARTIAL |
| Без отдельной проектной оценки | 4 источника: Unreal Agent, CERA-MoA, KVTether, Random Attention |
| Экспериментальные envelopes | 3 ограниченные записи; прочие raw результаты и протоколы сохранены через linked_materials |

Отсутствие отдельной оценки не означает отрицательный результат: у видео исходный метод неизвестен, а у трёх backend-dependent работ исходники явно указывают NO_CURRENT_TARGET. Это не бессрочный запрет применения и не новая оценка всех 45 проектов.

## Проверка работы исполнителей

Три сабагента gpt-6-luna подготовили раздельные фрагменты по 25, 25 и 24 карточки. Проверяющий сверил их, нормализовал стабильные ID и исходные формулировки, добавил полный импорт прототипа DSH и пропущенные явные строки матриц. Черновики не публиковались автоматически.

Исправлены ошибки черновиков: упоминание Wiki_PG только в ограничении MemComposer не стало рекомендацией; code review не помечен как engineering article; историческая оценка не выдана за новое чтение. У NovaFabric, LIMBO, VeriHarness и sequential diagnosis сохранены разные научные и технические/операционные записи. Производственные утверждения TrinMedicalBot остаются историческими документальными сведениями с clinical-review pending, а не клиническим доказательством.

Проверки теперь контролируют точную строку, целевую колонку, принадлежность строки исследованию, контекст заголовка, полное множество строк JSON, current/supersedes, исходные ссылки и hash аналитического тела каждой карточки. Исходные обзоры, raw данные, Telegram ledger, архив и код экспериментов не переписывались.

## Ограничения результата

Завершена нормализация всех карточек, а не исчерпывающая перепроверка применимости каждой работы ко всем проектам. Документальный кандидат не равен verified seam. Старые научные результаты и проектные оценки не стали актуальными измерениями только из-за переноса в JSON.

Дополнительная финальная read-only структурная проверка завершена без блокирующих замечаний в своём ограниченном scope. Это повторная проверка с участием исполнителя одной из партий, а не полностью независимая научная экспертиза всех источников. Локально прошли 29 тестов, генерация, проверка ссылок и provenance; post-push сверка и CI выполняются при публикации. Сведения о запусках доступны в [GitHub Actions](https://github.com/Artemedi/research-hub/actions).
