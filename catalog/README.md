# Описание каталога

[structure.json](structure.json) задаёт список карточек, канонические документы и соответствие опубликованных старых адресов. Он не определяет доказательный статус источников.

- `studies`: полные пути карточек без общего индекса.
- `documents[].to`: единственный редактируемый путь обзора или данных.
- `documents[].kind`: `review`, `portfolio`, `collection`, `project-fit` или `data`.
- `documents[].title`: предметное название для оглавлений.
- `documents[].from`: старый адрес либо `null` для нового материала.
- `documents[].date`: дата записи; обязательна для нового материала без `from`.
- `original_sha256`, `legacy_headings`: provenance переноса и совместимость прежних разделов. Для новых записей не требуются.

Генерация: `node scripts/build-catalog.mjs`. Проверка без записи: `node scripts/check.mjs`. Генерируемые файлы имеют служебный комментарий; в них не добавляют ручные записи.

Размещение и правила имён описаны в [архитектуре](../docs/architecture.md). Исследовательские требования — в [протоколе](../RESEARCH_POLICY.md).
